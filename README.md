## 运行

直接用浏览器打开 `index.html`，无需安装或构建，无远程素材依赖；file://下采样读取失败会使用实时合成声音。完整采样建议用下述本地HTTP服务。

推荐双击根目录的 `start-game.cmd`，它会在后台启动本地服务；关闭启动窗口后服务继续运行。重复启动会复用正常运行的服务，不会重复占用端口。运行日志保存在 `.local`，不纳入 Git。

也可以在本目录的 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-preview.ps1
```

访问 [http://127.0.0.1:8877/](http://127.0.0.1:8877/)。更换端口：在上面的启动命令后加 `-Port 8880`。此服务只监听本机回环地址，电脑重启后需要重新启动。

调试时也可在前台运行，终端必须保持开启：

```powershell
node scripts/serve.js
```

前台模式更换端口：`node scripts/serve.js 8880`。地址无法访问时，先检查服务是否正在运行；若日志提示端口被占用，请关闭之前的预览服务或选择其他端口。服务的状态接口为 `/__preview/health`，启动器会用它确认正在运行的是本项目。

## 可玩的内容

- 剧情《把黎明送回六域》：七章、23 段主线对白、七份线索、逐章授权、有限敌方生产、两种胜利模式、重试、参谋建议与自愿协同接管。
- 自由战役《六域演习》：271/547/919 格、九套固定地图、三种随机地貌、可复现种子、完整地图预览和明确的失败回退。
- 2—6 方独立经济、本地轮流操作与四档 AI；支持各自为战、2v2、3v3、2v2v2，盟友共享视野。
- 38 种单位、十个三级体系和八种特殊单位；海陆空状态、单格占位、累计移动、道路奖励、能耗、攻击预览、反击、全单位占领与技能。
- 九类建筑、资金和能源收入、建设地基、升级、独立生产订单、固定自动部署格、每设施三支 FIFO 库存和 24 编制。
- 当前视野与最后观测建筑、总部淘汰/全部建筑胜利、投降、同意和局、停滞判据、终局统计。
- 五个自动存档、四个回合起点、十二个命名存档、JSON 导入导出；读档不重新发放收入或重新生成地图。
- 军种/体系/生产等级图鉴筛选、行动手册及独立规则测试场。

## 基本操作

触屏与手写笔采用先预览再确认：单指拖动、双指缩放，目标面板展示路线、能源和反击；长按不会绕过确认。单位面板与小地图可收起，结束回合独立保留。鼠标操作仍直接下令。

左键选中己方单位后，直接点击目的地移动、敌军攻击、可接管据点占领；右键也可直接下令。鼠标移动不需要确认，点击同格敌军与设施时默认进行一次攻击，设施为驻守单位分担四分之一伤害，无需二选一。悬停可查看路线、能源和战斗结果。每单位 2 AP，两次移动共用整个己方回合的移动预算；攻击、占领和大多数主动技能使用后结束该单位行动，应急修复只消耗 1 AP。

点击己方生产设施下单。设施管理将状态、升级和部署按钮集中显示，仓库在底部用一行头像与角色名表示；说明与禁用原因在悬停1.5秒后出现。可在设施内“设置自动部署格”，选择设施本格或兼容邻格；港口默认选择相邻海洋。生产按所属方回合推进，完成后直接出现在部署格。部署格有单位时按生产顺序暂存最多三支，格子空出即自动部署队首，不再逐支点击部署；库存满时暂停接单。其他方行动阶段自动出库的新兵没有行动点，下个己方回合恢复。部署设置随存档保存。

单位移动到可接管建筑的实际终点，移动消耗 1 AP 后若仍有至少 1 AP，会自动占领并结束行动；经过的建筑不会自动占领，AP 不足可下回合在同格占领。占领必须位于建筑本格，邻格不能占领；点击“占领”只高亮单位所在格，并标记合法据点或阻挡原因。总部和生产设施为同格友军分担25%伤害；城市、贸易站和能源设施不设HP。损毁设施可付费恢复至50%，完好设施在所属方回合开始按等级自动恢复5%/7.5%/10%。地图文字采用独立最上层标签，允许超出六边形，选中或悬停显示完整说明。

点击地图内的“建设”选择建筑，再直接点击合法格开工，不消耗单位 AP。

地图占满游戏窗口，生产、部队、目标、菜单和存档都通过地图内浮层操作。WASD / 方向键移动镜头，滚轮缩放，空格暂停或继续游戏、动作和声音。Tab 聚焦格子，Enter 选择或下令，Esc 关闭浮层或取消选择；M 移动、F 攻击、C 占领、Q 技能、N 下一部队、H 总部。多人本地交接须先确认遮挡页。

存档保存在当前浏览器、当前访问地址的本地存储中。换浏览器、端口或从文件访问切换到服务器访问时，使用 JSON 导出/导入携带存档。旧 v0.4 工作台没有完整回合快照，导入会明确提示不兼容；完整快照中的旧能源字段提供一次性迁移和冲突检测。

## 人机难度

| 难度 | AI 单位生命 / 火力 / 装甲 | AI 资源 | 决策 |
|---|---|---|---|
| 简单 | 85% / 85% / 90% | 100% | 基础调度，前八回合克制总部进攻 |
| 标准 | 100% / 100% / 100% | 100% | 常规夺点、攻击、修复和生产 |
| 困难 | 100% / 100% / 100% | 100% | 威胁评估、集火、保命走位、反制生产 |
| 地狱 | 120% / 120% / 110% | 初始与收入 150% | 更重视集火和风险控制 |

剧情章节与自由战役开始前均可选择。AI 始终按自身视野决策；地图内的人机决策区只显示观察方可见的行动说明。旧 training / challenge 存档映射为简单 / 困难，读取时不重复叠加倍率。

移动、射击、反击、击毁、占领和八种主动技能均有动画和本地合成音效；移动后自动占领与批量生产出库按真实结算顺序播放。海面加入缓慢高光，环境声按当前视野中的镜头位置呈现海风、海浪或轻机械氛围。首次人类点击或按键后启用声音，菜单可独立关闭环境声、调节总音量和加速 AI 动画。暂停和离开战场关闭声音输出。

## 开发入口

| 文件 | 职责 |
|---|---|
| `src/data.js` / `src/art.js` | 单位、建筑、地形数值与 SVG 绘制 |
| `src/content.js` | 从正式设计附件适配的离线地图和剧情内容 |

| `src/campaign.js` | 剧情队列、章节进度、线索和协同接管 |
| `src/storage.js` | 快照、校验、迁移与本地保存 |
| `src/controls.js` / `src/battle-ui.js` / `src/ui.js` | 直接指令、全屏地图、浮层与浏览器交互 |

| `game.css` / `battle.css` | 大厅、图鉴与战场布局 |

## 验证和维护

```powershell
node scripts/verify.js
```

统一运行规则回归、部署与占领、操作与控制器集成、540 次地图批次/27 组复现、自动对局，结果写入 `reports`。也可分别运行 `verify-core.js`、`verify-deployment.js`、`verify-controls.js`、`verify-ui.js`、`verify-ui-integration.js`、`verify-board-v0.9.js`、`verify-fx.js`、`verify-art.js`、`verify-ai.js`、`verify-maps.js`、`verify-battles.js`。所有脚本只用 Node 内置库。

`node scripts/export-assets.js` 生成 76 个单位、8 个地形、75 个建筑 SVG；`node scripts/export-portraits.js` 生成六个人物 SVG 肖像。`node scripts/build-content.js` 从正式 JSON 和对白标记生成运行内容。`node scripts/export-runtime.js` 导出运行数据到 `reports/runtime-data-v0.7.json`。`node scripts/export-traceability.js` 生成 155 项实现对照。新的 `export-design.js` 转发到运行数据导出，保留人工设计文档。
