# 六域：边境交锋 v0.8

可在浏览器中直接运行的六边形回合制战略游戏。已接入 v0.5 基础规则、v0.6 七章剧情和 v0.7 能源、自由战役与 2—6 方对战规则。

## 运行

直接用浏览器打开 `index.html`，无安装、前端依赖、构建或联网资源请求。

也可以在本目录运行：

```powershell
node scripts/serve.js
```

访问 [http://127.0.0.1:8877/](http://127.0.0.1:8877/)。更换端口：`node scripts/serve.js 8880`。服务器只监听本机回环地址。浏览器预览当前使用 8877，原 8765 服务未被替换。

## 可玩的内容

- 剧情《潮线上的命令》：七章、23 段主线对白、七份线索、逐章授权、有限敌方生产、两种胜利模式、重试、参谋建议与自愿协同接管。
- 自由战役《六域演习》：271/547/919 格、九套固定地图、三种随机地貌、可复现种子、完整地图预览和明确的失败回退。
- 2—6 方独立经济、本地轮流操作与四档 AI；支持各自为战、2v2、3v3、2v2v2，盟友共享视野。
- 38 种单位、十个三级体系和八种特殊单位；海陆空状态、单格占位、累计移动、道路奖励、能耗、攻击预览、反击、全单位占领与技能。
- 九类建筑、资金和能源收入、建设地基、升级、独立生产订单、三件库存、来源设施部署和 24 编制。
- 当前视野与最后观测建筑、总部淘汰/全部建筑胜利、投降、同意和局、停滞判据、终局统计。
- 五个自动存档、四个回合起点、十二个命名存档、JSON 导入导出；读档不重新发放收入或重新生成地图。
- 军种/体系/生产等级图鉴筛选、行动手册及独立规则测试场。

## 基本操作

左键选中己方单位后，直接点击目的地移动、敌军攻击、可接管据点占领；右键也可直接下令。移动不再需要确认，同格有多个合法攻击目标时才选择目标。悬停可查看路线、能源和战斗结果。每单位 2 AP，两次移动共用整个己方回合的移动预算；攻击、占领和大多数主动技能使用后结束该单位行动，应急修复只消耗 1 AP。

点击己方生产设施下单。生产按该设施所有者的己方回合推进，完工进入库存，再选择原设施格或合法邻格部署。点击地图内的“建设”选择建筑，再直接点击合法格开工，不消耗单位 AP。

地图占满游戏窗口，生产、部队、目标、菜单和存档都通过地图内浮层操作。WASD / 方向键移动镜头，滚轮缩放，空格暂停或继续游戏、动作和声音。Tab 聚焦格子，Enter 选择或下令，Esc 关闭浮层或取消选择；M 移动、F 攻击、C 占领、Q 技能、N 下一部队、H 总部。多人本地交接须先确认遮挡页。

存档保存在当前浏览器、当前访问地址的本地存储中。换浏览器、端口或从文件访问切换到服务器访问时，使用 JSON 导出/导入携带存档。旧 v0.4 工作台没有完整回合快照，导入会明确提示不兼容；完整快照中的旧能源字段提供一次性迁移和冲突检测。

## 人机难度

| 难度 | AI 单位生命 / 火力 / 装甲 | AI 资源 | 决策 |
|---|---|---|---|
| 简单 | 85% / 85% / 90% | 100% | 基础调度，前八回合克制总部进攻 |
| 标准 | 100% / 100% / 100% | 100% | 常规夺点、攻击、修复和生产 |
| 困难 | 100% / 100% / 100% | 100% | 威胁评估、集火、保命走位、反制生产 |
| 地狱 | 120% / 120% / 110% | 初始与收入 150% | 更重视集火和风险控制 |

剧情章节与自由战役开始前均可选择。AI 始终按自身视野决策；地图内的人机决策区只显示观察方可见的行动说明。旧 training / challenge 存档映射为简单 / 困难，读取时不重复叠加倍率。

移动、射击、反击、击毁、占领和八种主动技能均有动画和本地合成音效。首次人类点击或按键后启用声音，菜单可静音、调节音量和加速 AI 动画。

## 开发入口

| 文件 | 职责 |
|---|---|
| `src/data.js` / `src/art.js` | 单位、建筑、地形数值与 SVG 绘制 |
| `src/content.js` | 从正式设计附件适配的离线地图和剧情内容 |
| `src/grid.js` / `src/maps.js` / `src/random.js` | 轴坐标、寻路/视线、九套固定图、七关与随机生成 |
| `src/game.js` | 完整行动事务、经济、技能、视野与胜负 |
| `src/ai.js` | 基于观测信息的合法 AI 决策 |
| `src/campaign.js` | 剧情队列、章节进度、线索和协同接管 |
| `src/storage.js` | 快照、校验、迁移与本地保存 |
| `src/controls.js` / `src/battle-ui.js` / `src/ui.js` | 直接指令、全屏地图、浮层与浏览器交互 |
| `src/fx.js` / `fx.css` | 按实际事务播放 SVG 动作与 Web Audio 音效 |
| `game.css` / `battle.css` | 大厅、图鉴与战场布局 |

`legacy/v0.4` 保留旧工作台代码及石油设施图标，仅供追溯，当前页面不加载它们。

## 验证和维护

```powershell
node scripts/verify.js
```

统一运行规则回归、操作与控制器集成、540 次地图批次/27 组复现、自动对局，结果写入 `reports`。也可分别运行 `verify-core.js`、`verify-controls.js`、`verify-ui.js`、`verify-ui-integration.js`、`verify-fx.js`、`verify-art.js`、`verify-ai.js`、`verify-maps.js`、`verify-battles.js`。所有脚本只用 Node 内置库。

`node scripts/export-assets.js` 生成 76 个单位、8 个地形、75 个建筑 SVG；`node scripts/export-portraits.js` 生成六个人物 SVG 肖像。`node scripts/build-content.js` 从正式 JSON 和对白标记生成运行内容。`node scripts/export-runtime.js` 导出运行数据到 `reports/runtime-data-v0.7.json`。`node scripts/export-traceability.js` 生成 155 项实现对照。新的 `export-design.js` 转发到运行数据导出，保留人工设计文档。

本轮交互、动作、美术与四档 AI 见 [交付索引 v0.8](docs/交付索引-v0.8.md) 和 [v0.8 交付与验收](docs/开发验收报告-v0.8.md)。此前完整结果见 [开发验收报告](docs/开发验收报告-v0.7.md)，逐项对应见 [功能实现对照](docs/功能实现对照-v0.7.md)，此前正式设计见 [交付索引 v0.7](docs/交付索引-v0.7.md)。

本轮 189 组自动检查、八场新增难度对局和既有 22 场自动对局通过；浏览器已检查直接指令、暂停和生产建设，后续浏览器权限被拒绝，最终 AI 界面未再次进行真实浏览器验收。音效未做人耳听测；真人首次游玩时长、先后手/多方胜率和数值平衡仍需实际玩家样本。联网房间、匹配、账号与远程同步属于文档明确保留的后续范围；当前提供本地轮流和 AI 对战。
