# 《六域：边境交锋》自由战役模式设计 v0.7

日期：2026-10-08。状态：可交付实现的设计规范。基础数值与操作使用[规则总册v0.5](规则总册-v0.5.md)；地图使用[自由战役地图设计](自由战役地图设计-v0.7.md)，多人胜负使用[多方对战规则](多方对战规则-v0.7.md)。本版只交付文档与地图设计附件。

## 1. 模式定位与菜单

主菜单设置两个入口：**剧情战役《潮线上的命令》**与**自由战役《六域演习》**。剧情战役继续使用v0.6的七关、对白与三小时完整主线预算。自由战役是一张地图上从初始据点到最终胜利的完整对局，玩家自行选择建设、三军发展、作战方向与结束节奏；它是可重复游玩的独立内容，不追加为剧情第八关。

自由战役发生在共同历218年航道危机后的联合演习期。六个辖区使用共同采购的近现代装备进行模拟作战，争夺港务、能源与指挥网络。开场使用一段可跳过的说明，结算使用战况总结；没有新主线、隐藏剧情或必须完成的对白。六个席位代表本局参与者，不额外创建六套不同科技树。

进入路径：主菜单 → 自由战役 → 选择规模 → 固定/随机地图 → 人数与控制者 → 胜利目标与迷雾 → 预览 → 开始。单人默认是P1由玩家控制，其余席位由AI控制；支持本地轮流操作的多人设置，数据结构预留未来联网控制者。

## 2. 默认设置与可选项

| 项目 | 默认 | 可选择的范围 |
|---|---|---|
| 地图规模 | 小型 | 小/中/大，分别271/547/919格 |
| 地图来源 | 固定 | 固定地图或随机地图；随机可填种子和重新生成 |
| 参与方 | 2方 | 小型2方；中型2—4方；大型2—6方，含人类与AI总数 |
| 胜利目标 | 占领总部 | 占领总部/占领全部建筑；多人含义见对应规则 |
| 阵营关系 | 各自为战 | 4方可2v2；6方可3v3或2v2v2 |
| 控制者 | 1玩家，其余标准AI | 每席人类或AI；至少一个人类 |
| 迷雾 | 开启 | 开启/关闭，开局后固定 |
| 回合顺序 | 随机先手后固定顺序 | 房间预览顺序；开局后固定，不每轮重洗 |
| 操作时限 | 无 | 本版不设强制结束回合倒计时 |
| 起始资源 | 600金钱/60能源 | 正式预设固定；测试场的资源编辑留在原测试场 |
| 建造与升级 | 全部开放 | 按v0.5地形、控制范围、资源和设施等级条件执行 |
| 单位可用范围 | 全38种 | 四类生产设施逐级解锁，不受剧情关卡白名单限制 |
| 跨局继承 | 无 | 新对局重新配置，不继承剧情资金、部队、勋章收益 |

关闭席位后按实际人数重新加载对应固定布局或重新生成随机地图。不能把原六方布局中的某些完整基地直接改成无人资源包。地图预览确认后，任何影响人数、规模、来源或种子的修改都使原预览失效。

## 3. “全流程”的明确范围

每一档地图均包含八种地形、九类建筑、陆地与海洋能源点、完整的陆海空生产条件，以及十个三级单位体系和八种特殊单位的解锁途径。每方有四种Ⅰ级生产设施，可自行升级到Ⅲ级并生产全部38种单位；无需打通剧情或在其他模式先解锁。

地图的开局部队用于建立最初的行动选择。全部38种型号不同时塞进开局，每方24编制仍计入存活部队、订单与库存。“体验全部内容”表示本局可开展全部机制，并不要求为了结算生产38种不同型号。

| 体验阶段 | 玩家可以完成的事情 | 地图提供的条件 |
|---|---|---|
| Ⅰ 开局经营 | 了解收入、占位、移动、全单位占领 | 8座己方建筑、6单位、总部守军与邻近扩张点 |
| Ⅱ 资源扩张 | 占领城市、市场、能源站、海上能源平台 | 每方附近4个中立扩张点，海陆两种资源路线 |
| Ⅲ 建设与升级 | 新建建筑、修复受损据点、Ⅰ→Ⅱ→Ⅲ升级 | 每方2处空能源点、可施工地块、工程车、完整四生产设施 |
| Ⅳ 合成作战 | 步兵守点、装甲推进、炮兵支援、海军沿岸作战 | 中央据点、陆路与侧翼、连通海域、港口部署空间 |
| Ⅴ 空军与支援 | 侦察、战斗/轰炸、防空150%反击、电子战 | 机场全树、陆海防空、遮挡与开放空域 |
| Ⅵ 达成胜利 | 夺取敌方总部或控制所有建筑 | 可到达的目标与明确的多人结算规则 |

建议节奏为己方第1—3回合扩张、第3—6回合Ⅱ级与侧翼部署、第6—12回合Ⅲ级选择、第10回合后形成主要攻势。这是对局引导目标，不是强制科技时间表。玩家可以先走航空、先夺海洋能源，或保持低级单位规模化生产。

## 4. 可选体验清单

单人局右侧可展开“演习记录”，逐项记录移动、占领、生产部署、首次新建、首次工程修复、首次设施升级、首次海上夺点、首次空军侦察、首次专职防空反击与一次Ⅲ级型号生产，共10项。记录只作回顾，完成与否不改变胜负、收入、单位数值或下一局难度。

每个条目只说明操作与作用，例如“占领海上能源平台可以增加每回合的能源收入”。防空条目在实际合法反击发生后记录，不能仅因生产防空车就标记完成；修复条目要求HP实际增加。Ⅲ级条目在订单完成时记录，不要求同回合部署。

生产菜单显示“当前等级可生产”“下一等级新增”“最高等级全树”。特殊单位使用独立标签，仍说明生产设施及所需等级。所有单位都显示占领能力，基础步枪步兵保持80 HP、0装甲、30基础伤害。

## 5. AI与学习体验

| AI档位 | 决策定义 | 适用 |
|---|---|---|
| 陪练 | 前8个该AI己方回合优先扩张、建设与防守，不主动攻击或占领敌方原始总部；受击仍正常反击，其他建筑可争夺；第9回合转为标准策略 | 首次自由体验完整发展流程 |
| 标准 | 正常争夺资源、保护总部、建设升级，根据可见敌情组织三军与支援 | 默认对局 |
| 挑战 | 同资源与规则下，更重视集中火力、进攻时机、能源预算和多设施协同 | 熟悉规则后的重玩 |

AI的上述总部选择只是决策偏好，合法操作规则对所有方一致。陪练不保护玩家单位免死，也不替玩家自动修复。各档均正常支付生产、升级、建设及移动成本，遵守24编制、库存3、每设施单槽、迷雾、AP、反击和冷却。自由战役不沿用剧情七关的有限生产计划，也不使用免费边缘增援。

各自为战时，AI把所有敌对席位纳入同一评估，不因控制者是人类就固定集火。允许根据可见威胁进攻弱侧与争夺他方之间的资源，但不读取隐藏敌军、未探明的新建筑、敌方资源库存或尚未看见的技能状态。队伍局按团队目标协同，各自支付费用和控制部队。

## 6. 对局时长与保存

下表是单人对AI、默认人数、可跳过AI动画的设计目标，尚未经试玩验证。更多人类席位、深度经营与队伍交流可能延长时间。

| 规模/默认人数 | 总部模式 | 全建筑模式 | 建议用途 |
|---|---:|---:|---|
| 小型/2方 | 40—65分钟 | 55—85分钟 | 一次体验完整经营与三军作战 |
| 中型/4方 | 70—115分钟 | 95—150分钟 | 多方向对抗与队伍协同 |
| 大型/6方 | 110—170分钟 | 150—230分钟 | 六方资源争夺与完整战局演变 |

自由战役可中途保存并分次完成，没有到目标时长就强制失败、跳结局或接管获胜的规则。v0.6的150分钟剧情协同提示与180分钟主线预算仍仅作用于剧情战役。

在每个完整行动事务后、每次己方开始结算后与整轮结束后保存；保留至少最近3个自动存档，并允许命名手动存档。存档明确显示模式、规模、实际地图来源、种子、人数、队伍、胜利条件、当前轮及当前行动方。联机的保存权限后续由房间主持者管理，底层状态字段本版先定义。

## 7. 地图预览与结算

预览展示地形、初始建筑、出生区、人数、每方开局资产与胜利条件。公开的原始总部位置用于理解战场方向；预览不展示AI未来订单、行进路径或计划。开局部队已在文档中固定，随机地图随机的是地理与扩张布局。

开局后只显示当前视野与探明记录。全建筑模式提供目标总数、己方/本队已占领数和已知未占领目标；未探明的新建筑位置不因进度栏泄漏。详见[多方对战规则](多方对战规则-v0.7.md)的迷雾与登记表。

结算展示获胜玩家/队伍、胜利触发原因、规模与种子、轮数和活跃时长，以及生产/占领/建设/修复/能源消耗记录。投降、总部出局、胜利、和局是不同结果。多人失去自己总部后，可以观察仍存活队友的视野，不能继续指挥已经清除的部队或替队友下单。
