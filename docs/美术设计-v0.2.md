# 《六域：边境交锋》美术设计 v0.2

日期：2026-10-08。以三军、步兵和分级建筑为准；旧版机械步行兵和能源节点为历史草案。

## 风格

近未来架空军事工业风，人类步兵与常规装甲并存，工业设施和城市形成经济战场。参考 [EasyTech《世界征服者4》官方页面](https://easytech.itch.io/world-conqueror-4) 的军事战略题材方向，在本项目中以单位轮廓、设施等级和俯视地图建立可读性。单位、建筑、地图和界面采用原创设计。

棋盘使用俯视 SVG，以少量面片明暗增加体积；概念图允许斜俯视、烟尘和丰富材质。实际棋子优先辨认兵种、敌我、当前状态与范围。

## 三种状态

陆地单位轮胎、履带和脚部接触地面；海洋单位使用水线和波纹；空军使用离地阴影与飞机标记。飞机飞到海洋上方仍为空中状态。

海军陆战步兵在海上显示登陆艇，上岸后移除艇体、显示步兵小队，棋盘已实现该切换；军种仍为海军，选中面板显示陆地状态。下载的静态 SVG 采用登陆艇默认姿态，后续补充两态导出。两栖轻坦保留浮力侧舱。

每格最多一个地表单位和一个空中单位，用图层按钮分别选择；另一层仅显示小标记，避免大图重叠。攻击是否对空须以档案明确属性为准，不让玩家只凭雷达图形猜测。

尖顶六边形边长 44px；单位 viewBox 100×100，棋盘显示约 56px。建筑和驻军共格时显示设施徽记，HP 与敌我符号放在图标外侧，不遮住机翼和炮塔。

## 后续动效与验收

移动每格 120–170ms，直射 250–350ms，间接炮击 500–650ms，登陆切换约 350ms，设施完成 300ms。步兵短步循环、舰船尾迹、旋翼与飞机阴影各有反馈；保留事件记录，不用大幅震屏。尊重 prefers-reduced-motion，音效独立开关。当前工作台即时结算，无战斗动画与音效。

验收目标：48px 隐藏名字后仍能识别主要兵种；灰度下敌我靠徽记可辨；双层共格提示明确；登陆更新轮廓与状态；建筑等级可读；概念图与棋盘用途明确。动作、建筑受损、小屏与对比度在完整游戏阶段继续验证。
