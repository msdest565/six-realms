# 《六域：边境交锋》随机地图生成规范 v0.7

日期：2026-10-08。状态：生成算法与验收契约，尚未实现运行时生成器。适用小型2方、中型2—4方、大型2—6方；各档随机地图均开放全部机制。资源统一使用[能源系统](能源系统设计-v0.7.md)。

## 1. 随机范围与固定骨架

随机地图使用与[固定地图](自由战役地图设计-v0.7.md)相同的真实六边格边界、人数对应出生环、每方开局资产及中央工厂。随机改变海陆边界、海湾/岛状陆块、次要道路、浅河、山脊、碎石/废墟掩体及四类中立扩张建筑的具体位置。不会随机赠送Ⅲ级设施、额外资金或特别强的出生部队。

固定骨架保证玩家可从建设到三军作战体验全流程，地图的随机性来自战线、侧翼、遮挡与经济点组合。出生点可在房间中交换控制者；随机地形与玩家名字、AI难度、胜利模式、迷雾、团队设置和先手随机流分开。

| 地貌选项/ID | 目标方向 | 仍必须满足的条件 |
|---|---|---|
| 均衡沿岸 balanced_coast，默认 | 连续陆块、外海环线、适量侧湾，能源路线清楚 | 完整八地形/九建筑与公平开局 |
| 海湾走廊 bay_corridors | 海洋向内延伸，沿岸火力与狭长侧翼更多 | 港口、平台仍在同一海洋连通域；有两条陆路 |
| 群岛桥网 island_bridges | 增加岛状陆块与道路桥，空军/陆战队调度更多 | 预置陆地建筑均可地表到达；舰船绕行通路真实存在 |

三种地貌在三个规模都可选择。岛状陆块可以是无人地形；带预置陆地建筑的岛块须经合法地表桥路连通。桥梁道路不能当作舰船可穿越海洋，所以不能用一条横贯水道的道路假装兼有通航。

## 2. 种子与确定性

种子为1—64个Unicode码点，输入先进行NFC规范化，保留大小写与内部空格，去掉首尾空白。空输入时生成一个可复制的种子，再执行相同流程。预览展示规范化后的种子、生成器版本、规模、人数、地貌、候选序号和地图哈希。

候选序号a从0到39。候选初始状态为FNV-1a32对UTF-8编码的JSON数组["0.7",规模ID,人数,地貌ID,规范化种子,a]求哈希：起始2166136261，每字节先异或，再乘16777619并按无符号32位截断。状态为0时换为1831565813。

随机数使用xorshift32：依次x ^= x<<13，x ^= x>>>17，x ^= x<<5，每步按32位位运算执行，最终转为无符号整数。u=x/4294967296，取[0,1)。取候选数组索引用floor(u·长度)，洗牌使用Fisher–Yates从末尾向前。

遍历格子按q升序再r升序；席位按P序号；六邻格顺序固定为(1,0)、(0,1)、(-1,1)、(-1,0)、(0,-1)、(1,-1)。相同代价寻路先比较路径终点q/r，再比较上述邻格序号。不能依赖对象/哈希集合的偶然迭代、系统时钟或平台随机函数。

地图、席位绑定/先手、AI决策使用各自随机流。切换胜利条件或迷雾，不重新随机地图；AI运行也不能消耗地图生成随机流。地图算法改变后提升generatorVersion，旧存档保存真实格子与资产，不在读取时按新算法重生成。

## 3. 生成步骤

### G01 载入人数对应的固定骨架

读取JSON中匹配规模和人数的布局，复制边界、出生HQ、初始8座己方建筑、6单位、空能源点和中央工厂。暂移除每席4座中立扩张建筑及其建筑对应能源点；保留己方能源站和空能源点标记。未启用的席位既没有建筑，也没有完整免费扩张包。

### G02 标记不可破坏区域

保护全部己方建筑和单位所在格、总部半径2内的合法开局地形、军港三个海洋部署邻格、空能源点与其视野/建设来源。总部之外的侦察车格也单独保护。

在地表图上通过节点容量为1的路径检查，选取总部到中央的两条内部不共格路线，端点容量为2；将路径格标为地表保护，禁止改为海洋/山脊。优先最小移动代价，等代价按固定坐标顺序。空单位位置不参与地形路线判定。

保护最外两圈(radius=R−1、R)为海洋通航环，并保护每港至少一条连接外环的真实海洋路径及3个海洋邻格。由此随机化不能隔离海军或堵死初始舰船出入口。保护标签相互冲突时放弃该候选，不能覆盖先前的建筑合法地形。

### G03 生成海岸与主要地貌

在可变区域以固定布局地形为起点，先生成海陆簇，再补道路与地表内容。均衡沿岸、海湾走廊、群岛桥网分别以陆块完整度、内湾深度、岛状陆块比例为倾向。

按下述对称方式建立格子轨道，轨道按其中最小q/r坐标排序，每轨道抽取一次0—255整数噪声并赋给全部成员。含保护格的轨道全部固定为128，不抽随机数。之后进行两轮“本格及六个地图内邻格”的均值平滑；边界外邻格不计，均值取整向下，只读前一轮值，保护格保持128，不能边遍历边写入。按地貌阈值尝试转换海陆，保护区不参与转换。平滑后的等值候选按坐标排序并使用本候选随机流打破顺序。

均衡沿岸先用低于64的候选扩张海洋、高于192的候选缩回陆地；海湾走廊用低于96扩张、高于208缩回；群岛桥网用低于80扩张、高于176缩回。每次转换后保留待验收标签，最终以比例与连通要求决定接受，阈值不是无条件保证。

2/3/6方的可变区域优先按对应180°/120°/60°旋转轨道共享噪声与地形选择，轨道碰到保护区时整组跳过。4方使用180°成对处理后按各席预算校验；5方按最近出生区划分预算区并独立生成。不能声称六边网格可提供精确五重对称。

道路连接出生腹地、扩张区与中央，随机提供次要绕行。新建道路只在地表保护路线或规划连接路径上转换，不能不经航道检查就把海洋全宽截断。海岸在陆地贴海区域中分配，军港与出生城市保持海岸。

### G04 放置掩体、浅河与山脊

在不含己方建筑/单位/能源点、部署空格、受保护路径的候选格中放置碎石、工业废墟、浅河、山脊。山脊不置于唯一通路；废墟遮挡不封死港口所有地表观察方向。至少有一条连续3格的浅河/碎石/废墟组合区域，使地形效果可在一次推进中体现。

每类点位按距各HQ的移动代价分为本方近区、前线区与中央区；距离多个HQ相同时，归中央共享预算，不固定全部让给较小P序号。各方近区的同类掩体格数量差≤2，山脊/废墟的前线阻挡数量差≤2。若无法兼顾保护区和预算，当前候选失败。

### G05 放置四类扩张点

先为城市、市场、陆地能源站与海上能源平台分别抽取一个全体席位共享的目标移动代价；城市/市场3—5，陆地能源站4—6，平台距初始防空舰2—4。每席从匹配该目标或±1、且仍处于本类允许区间的合法地形候选中选择，不改变己方基地资源。

先城市，后市场，再陆地能源站，最后海上能源平台。已放建筑、初始单位、空能源点、中央工厂不可重叠。城市/市场/陆地能源站在荒原、道路、海岸；平台只在连通海洋。建筑下方不放山脊、浅河或废墟地形。新增能源设施同时登记其能源点。

每类扩张点从对应总部或初始舰船计算的实际静态移动代价在所有席位间差≤1；每席四类总预算差≤2。目标点需靠近相应席位的展开方向，不落入他方HQ半径2或他方初始基地内；相邻对手也能进入争夺，资源不是永久专属。

中央工厂固定(0,0)、Ⅰ级、满HP、中立，没有初始订单和库存。新放建筑与既有建筑至少不同格，地图加载后不自动转成合法地形。

### G06 校验与有限修复

按下一节全部条件校验。每候选至多8次修复，固定优先级为建筑合法性/保护区 → 地表连通 → 海洋连通 → 部署 → 移动预算公平 → 地形比例。只允许更改未保护地形或尚可移动的中立建筑；不能改变单位数值、初始资金、出生资产或原始总部位置。

合法性失败不能靠修改建筑类型或赠送飞机绕过。修复后从首项重新检查全部条件。一个修复操作只处理一个明确问题，例如扩大某航道一格或换一个中立市场候选；不能无限迭代直到输出。

### G07 确认或回退

首个完全通过的候选形成预览，记录acceptedAttempt和检查摘要，玩家可重新生成另一个种子。40候选均失败时，回退到相同规模/人数的固定布局，明确显示“随机生成未满足地图条件，使用固定备用地图”。实际来源写fixed_fallback，保留用户输入种子作记录，不能把固定地图伪称该种子的随机地图。

## 4. 硬验收条件

移动成本审核使用通用地表规则：荒原/道路/海岸1；碎石/废墟/浅河2；山脊与海洋不可进入。侦察车例外与道路+1预算用于实际单位首轮冲点的专项验收，不混入通用地形成本。海军图仅允许海洋，每步1。静态检查忽略单位临时阻挡。

| 项目 | 必须满足 |
|---|---|
| 边界与唯一性 | 完整271/547/919格；无重复坐标、边界外格或缺格 |
| 人数与出生资产 | 按规模人数表；每方8建筑6单位，同等级/HP/资源与守军 |
| 地形种类 | 八种全部存在，每种至少3格；以下比例同时成立 |
| 地形比例 | 海洋38%—54%、海岸4%—14%、道路4%—14%；山脊/废墟/碎石各1%—4%；浅河1%—3%；余下为荒原，至少10% |
| 初始建筑 | 12N+1，全9类；所有初始建筑满HP/Ⅰ级，无订单库存 |
| 新建条件 | 每席空陆地/海洋能源点各1个，距自己的完好HQ/城市≤2，当前视野可见，可新建 |
| 陆路 | 各HQ到全部陆地建筑可达；到中央至少两条内部不共格路线 |
| 海路 | 全部海洋在同一连通域；各港和全部海洋平台都可舰船到达 |
| 港口 | 至少3海洋邻格，至少2个初始无单位的舰船部署格 |
| 地面设施 | 步兵营、工厂、机场各至少3个初始空地表合法部署格；飞机另按自身地形权限部署 |
| 总部间距离 | 小型≥10，中型≥9，大型≥13；出生HQ不能被随机移动缩近 |
| 中央移动成本 | 小型≤8，中型≤13，大型≤18；全体席位差≤1，五方允许≤2 |
| 扩张公平 | 每类资源移动代价在全体席位间差≤1，四类总预算差≤2；处于本节规定区间 |
| 初始能源 | 每方收入120金钱/14能源，首可操作720/74，无随机资源奖励 |
| 叠格与目标 | 单位互不重叠，建筑互不重叠；建筑+单位允许；空点不计胜利目标 |

比例按整数格数验收：下限用ceil(比例×总格数)，上限用floor。所有条件同时通过；地貌选择不放宽胜利目标可达性。随机图比例仅约束随机成功候选，不能套用到作为独立人工设计的全部固定变体。

## 5. 防止首轮捷径与经济偏置

保留每HQ初始守军，不依赖全局无敌或“某型号不能占HQ”的限制。运行时验收需枚举可部署Ⅰ级飞机/侦察车的最早到达路线，并确认不能在未清除守军时占领HQ。

所有方按自己第一次开始发初始收入；不能让先手已经拿收入而末手永远少收一轮。若先手在末手第一次行动前攻击其建筑，末手按真实存活/归属建筑结算，不补发隐藏保护收益；需要用出生间距和守军控制风险。

禁止对某席位额外放一座市场作为平衡补偿。公平修复调整地理与距离，保持相同经济资产和科技门槛。先后手胜率、五方实际前线压力和多方围攻只能通过试玩验证，静态检查不直接证明50%或1/N胜率。

## 6. 存档与生成测试

保存normalizedSeed、generatorVersion、size、playerCount、landscapeId、acceptedAttempt、actualSource、contentHash、实际terrain/建筑/初始位置与当前局面。读取存档使用保存的实际地图，不依赖当前生成器重跑。

实现时建立固定种子测试集，每种规模/人数/地貌至少20种，覆盖中文、英文、数字、空格与最大长度；总计9个人数配置×3地貌×20=540张成功候选或显式回退。对其中每种组合至少1个种子跨刷新复现哈希，共27组；改变胜利模式/迷雾/AI档位不改变地图；改变生成器版本应有明确兼容处理。

另构造失败测试：港口隔离、全宽桥截航道、山脊封单路、总部被中立建筑占格、六方小地图、隐藏新建筑泄漏、40候选失败、修复次数超限、资源点类型错误。不能只测试“生成了一个可画出来的地图”。

本版交付的是可实现生成规范及完整固定备用数据；没有已运行的随机生成器，因而不提供伪造的随机地图黄金哈希或随机地图通过率。
