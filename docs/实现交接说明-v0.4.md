## 分工与版本依据

本聊天后续专职负责文档开发，包括游戏规则、单位设计、数值表、变更说明和验收要求；实现 agent 负责运行代码、数据接入、界面和实现测试。本次交接只新增文档，不修改游戏代码。

当前实现基线为v0.4。数值与单位规则使用v0.4文件，旧版内容只用于未被替代的背景与全局方案。若文档与代码不一致，应指出差异并按已确认文档同步实现；需要新增规则决策时记录问题，由文档侧补齐，避免自行恢复旧限制。

六份v0.4设计文档最初由 `scripts/export-design.js` 从代码数据导出，验证记录与本次交接文件为独立文档。后续以用户确认的文档版本推进设计；实现侧不要运行旧导出脚本覆盖新编写或已评审的文档。数据变化须明确记录，不将代码现状直接当成新设计决定。

## 必须保留的当前规则

| 项目 | v0.4基线 |
|---|---|
| 单位规模 | 陆军17、海军11、空军10，共38；十个体系各三级，另有八种特殊单位 |
| 等级 | 主体型号等级对应设施生产门槛；不是经验等级；高级设施保留低级型号 |
| 通用占领 | 全部单位，包括飞机、舰船与特殊单位，均可占领建筑和总部 |
| 占领条件 | 本格或相邻格；建筑内任一图层没有存活敌军；至少1 AP；占领后结束行动 |
| 占领收益 | 保留建筑等级，转移归属；收入从下一次结算生效；生产设施立即可接管 |
| 步枪步兵锚点 | 80 HP、0装甲、30固定基础伤害；30取自用户提出的20–40设计区间，当前没有随机伤害机制 |
| 战斗量级 | HP、装甲、伤害、目标加成采用10点步长；全部型号以单位设计表为准 |
| 伤害 | max(10,基伤＋一种目标类别加成＋一种陆海空状态加成−装甲−地形减伤) |
| 地形减伤 | 碎石10，废墟20；空中目标不享受地形减伤 |
| AP | 每回合2；移动花1；攻击或占领花1并结束行动 |
| 炮兵 | 三个等级均有相邻格射程盲区，移动后不能攻击；战列舰可移动后炮击 |
| 能耗 | 按实际进入格累计；步兵免能源；两栖轻坦陆1／海2；攻击和占领不扣能源 |
| 移动与图层 | 地表和空中各占一个位置；普通舰船不能上岸，可从相邻海洋格占领沿岸建筑 |
| 对空权限 | 仅显式具备防空能力的单位可以攻击空中；防空射程目前是主动攻击范围 |
| 生产 | 门槛与生产时间分别配置；每个设施实例独立工作；库存保留生产来源 |

总部已可占领，当前工作台尚未触发总部胜负判定。不能将“胜负尚未实现”理解为“总部仍不可占领”。

## 实现入口与数据约定

| 路径 | 用途 |
|---|---|
| `D:\AI\回合制战略\src\data.js` | 单位、体系、建筑、地形、经济与战斗配置 |
| `D:\AI\回合制战略\src\hex.js` | 地图、图层、领域、路径、攻击和占领校验 |
| `D:\AI\回合制战略\src\economy.js` | 建筑实例、资源、收入、订单与库存来源 |
| `D:\AI\回合制战略\src\app.js` | 工作台交互与界面显示 |
| `D:\AI\回合制战略\src\art.js` | 原生SVG绘制 |
| `D:\AI\回合制战略\scripts\verify.js` | 现有规则与资产回归检查 |

单位 `id` 为稳定引用；`system` 为主体体系，特殊单位为null；`modelLevel` 为型号等级，特殊单位为null；`tier` 为设施门槛；`buildTurns` 为独立生产时间。`armor` 是固定减伤，不是百分比；类别加成和状态加成分别结算。`capture` 当前全部为true，不能再由 `infantry` 推导。

建筑 `id` 表示类型，`key`／地图 `siteId` 表示具体实例；订单用 `facilityKey` 定位设施，库存用 `stockFacilities` 保留来源。实现扩展时不能把同类不同建筑合并成一个等级或一个工作槽。

## 验收基线

现有 `node scripts/verify.js` 的38项检查全部通过；浏览器已验证轰炸机占领兵营、从占领兵营生产并部署步枪步兵、占领总部、正确增加下一次收入、恢复场景，以及新量级伤害预览与执行一致。证据见 [验证记录](验证记录-v0.4.md)。

后续实现需保持：

- 任一军种与特殊单位不因分类失去占领能力，总部使用通用占领规则。
- 步枪步兵仍为80／0／30，全部38种单位数值与正式设计表一致；预览与执行共用计算规则。
- 地形预算、实际能耗、层占位、最小射程和炮兵移动禁射继续有效。
- 占领保留等级、不提前发收入、不能重复计入收益；两个同类设施独立生产，成品部署到实际来源设施。
- 新实现机制分别补充行为验收；历史38项通过不能替代新功能验证。
