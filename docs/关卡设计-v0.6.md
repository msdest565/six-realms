# 《六域：边境交锋》关卡设计 v0.6

日期：2026-10-08。七关战役《潮线上的命令》的关卡规范。本文件与[设计配置附件](战役关卡配置-v0.6.json)由同一份关卡清单整理；附件是设计数据，不是已接入的游戏模块。剧情见[剧情设计](剧情设计-v0.6.md)，对白与触发见[战役流程与剧情脚本](战役流程与剧情脚本-v0.6.md)。

## 共同规则与阅读方法

- 全地图为轴坐标平行四边形，(q,r)就是(列,行)，从0起算；不能使用旧测试场的奇数行偏移坐标。未指定格为荒原，地形规则从上到下覆盖。附件用water表示浅河，与既有地形代码一致。
- 玩家先手；每关资源在首次收入前记录。双方首次行动仍按当时完好建筑结算收入，单位属性和技能沿用v0.5。只有C02受损轻坦80/120 HP、城市废墟0 HP是明示场景状态，不是新单位数值。
- 地图只有列出的建筑和单位，建筑ID加关卡前缀形成永久实例ID。未标HP者满HP，未标状态者完好；初始队列与库存空。单位与建筑共格允许，单位与单位共格禁止。
- 每关都有一支初始己方总部守军，避免教学期开局空总部被直接占领；是否调出由玩家决定。
- 每关均有两个原始总部，开局选择的胜利模式始终适用。总部模式：接管敌原始总部即胜；全建筑模式：拥有本关所有登记建筑即胜，废墟也计入。
- 双方新建关闭，设施升级正常但遵守本关授权上限；玩家生产清单不改变型号数值或真实设施门槛。初始敌军可以有未授权给玩家补给的型号。
- 敌补兵表是有限的合法生产计划，必须付款、等待、保留来源及检查部署；不能按表直接生成免费单位。实际合法条件不满足时延后，设施丢失/归零则取消。
- 主线没有保护某个特定单位、全歼或限轮附加条件。每关一个可选目标，只发纪念章，不锁剧情或后续补给。

完整覆盖范围、存档、接管与时间规则见[战役规则与时长控制](战役规则与时长控制-v0.6.md)。

## 关卡调优优先级

地图与初始兵力是可验证的首轮基线，目标轮数不是已经跑通的攻略。完成实现后用两种模式实际试玩：先查必经路线、守军清除和最后占领是否连贯；再查能源是否足够、港口/机场是否堵塞、敌方有限补兵是否使胜利反复推迟。

若超过预算，先缩短路程、减少敌生产计划或将最后建筑靠近主路；仍保留完整主线、两种胜利选项和通用占领规则。不得把最后一点收尾改成隐藏全歼。验证规范见[战役验收与实现交接](战役验收与实现交接-v0.6.md)。
