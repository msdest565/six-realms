# 《六域：边境交锋》变更说明 v0.6

日期：2026-10-08。主题：新增剧情与关卡，七关主线可在三小时预算内完整体验。v0.6是战役层，基础战斗、38型号和9类建筑继续使用v0.5规范。本轮只修改文档及文档附件。

## 用户要求与对应设计

| 要求 | 设计结果 |
|---|---|
| 剧情与关卡同步 | 每关占领一个承载主线记录的敌总部，线索直接引出下一地点 |
| 架空历史 | 六域共同体、共同历218年，中央与地方围绕航道权限冲突；不对应现实国家 |
| 科技接近现代 | 坦克、舰船、飞机、雷达与无线电；不依赖科幻武器或万能信息技术 |
| 三小时内体验全部剧情 | 七关、23段主线；总部模式143分钟、全建筑157分钟，加重试/缓冲控制180分钟 |
| 完整剧情与关卡 | 世界背景、六名人物、完整对白、七张地图、兵力/资源/建筑/敌计划、胜负与验收同步交付 |

## 保留的已确认规则

玩家依然可以选择占领敌总部或占领全部建筑获胜，两种模式都有完整主线和相同结局。所有单位可占领，单格只容一单位、允许单位与建筑同格；专职防空150%反击；工程车每己方回合一次技能；HP与伤害数值不改。

战役不添加全歼、保护英雄、限轮或摧毁总部的隐藏胜负条件。建筑剧情副标题仍对应原九类建筑，不生成额外例外建筑。

## 新增的战役情境选择

固定玩家先手、每关资源/部队重新预设、没有跨关永久损失；C01—C03关闭迷雾，C04起开启。为了控制全建筑残局，七关双方关闭新建，但保留既有设施的合法升级与生产。玩家补给逐步授权，敌补兵是有限的真实付费订单，标准对局继续保持v0.5建设与设置规则。

可选目标只给纪念章，不锁真相与结局。新增参谋建议和玩家主动选择的协同接管：接管可推进故事，单独标记完成方式，不伪造标准战术胜利。150分钟时可选择优先体验剩余主线，没有强制失败倒计时。

近现代战役文案把“长钉磁轨炮”解释为长身管反坦克炮，把电子战平台底盘解释为六轮结构；不改变单位代码或数值，旧v0.5档案保留历史表述，战役显示采用本版世界设定。
