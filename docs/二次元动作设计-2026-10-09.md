## 1. 动作方向

棋盘保持 2.5—3 头身成年机装少女，动作表达“人物有情绪，装备有重量”。人物头部和眼神提供亲近感；履带、枪托、支撑脚、推进器承担运动和后坐力。步兵的利落、坦克的稳健、舰装的流动与航空的轻快必须从剪影和节奏辨认。

完整立绘负责精致展示，棋盘动作负责指令反馈。一般攻击使用 Q 版人物与机装，不插入全屏立绘演出。单位详情可有一次轻微眨眼／呼吸，生产预览可有收拢机装的展示姿态；这些是展示资源，不占战斗事务时间。

以下原则适用于全部型号：

- 身体随装备运动，固定主炮通过炮架后坐，不把人物当炮弹甩出去。飞行靠机翼、发动机或旋翼；海上由浮力平台承载。
- 动作重心稳定，裙摆、发梢和飘带只提供二级运动；小尺寸优先脸部、武装和兵种轮廓。
- 受击表现装备擦火、身体短暂缩肩和机装失衡。退场表示失去参战能力，以熄灯、设备碎片和短烟表达战损；保留损失的代价。
- 特效表达现有规则结果。漂亮的雷达、盾牌、机翼和潜舰不会附带自动拦截、隐身、飞行越权或复活。
- 单位 ID、数值、AP、通行、视野、反击、冷却和旧存档字段在首阶段保持。动作不引入新技能。

## 3. 十个常用动作状态

“状态”是表现层状态，不替代核心游戏状态。反击复用 `attack`，已行动／状态异常是 `idle` 参数，避免额外堆出完整动画套数。

| 状态 ID | 画面设计 | 触发与退出 | 最小制作要求 |
| --- | --- | --- | --- |
| `idle` 待机 | 轻呼吸；眼神专注；发动机和航灯低强度稳定运行 | 无事务；AP=0 时机装收紧、姿态静稳 | 1 静态姿态＋可选 2—4 循环关键帧 |
| `selected` 选中 | 抬眼／点头、武器轻收紧；阵营底环一次确认 | 玩家选中；约 180ms 后回待机 | 2 关键帧；重复选中限频 |
| `move` 移动 | 步态、履带或推进与实际路径联动 | 每个实际可见路段，终点收势 | 每族 4—6 帧或分层周期 |
| `transition` 海陆转换 | 浮舱展开／收拢、艇装换履带或步态 | 仅浪锋／破浪／礁盾／涉潮，实际域改变 | 海／陆各 1 稳定姿态＋2 转换帧 |
| `attack` 攻击／反击 | 目光锁定→架枪／稳定炮架→发射→回稳 | 已结算的 shot；`counter=true` 加反击标记 | 准备、发射、后坐、回稳 4 关键帧 |
| `skill` 技能 | 与现有八主动技能对应的机装操作 | 已结算技能；状态提示在确认点出现 | 具体技能见第 6 节，不给基础作战新增主动演出 |
| `hit` 受击 | 护甲擦火、短缩肩／机装侧倾；HP 数值确认 | 已观测命中，伤害已知才显示数字 | 2 关键帧；禁止连续闪烁 |
| `exit` 退场 | 机装熄灯→局部烟与部件→透明消失 | 核心确认单位失去参战能力 | 3 关键帧；无战场复活或相邻格逃跑 |
| `deploy` 部署 | 校验灯亮、机装展开、角色进入稳定战斗姿态 | 可见的新实例，按事件队列顺序 | 2 关键帧＋单圈确认 |
| `capture` 接管 | 少女操作通信终端，建筑接管徽记一次亮起 | 核心确实占领，旧归属到新归属 | 人物工具姿态＋建筑徽记，航空为接管探针 |

受击与退场按互斥的同一次命中处理。致命命中用 `hit` 的短擦火直接进入 `exit`，不先完整受击再重复爆破。不能反击的型号仍有受击，不能因此给它播放发射动作。

## 4. 兵种动作族与全部三十八型号

动作族复用时序和约束，角色、装备、表情和轮廓分别制作。三级单位通过支架／装甲／引擎体量、后坐和收势显示分量，保持同一速度档的总时长，不让重型号每次行动额外等几秒。

## 5. 三档统一时间轴与音效锚点

时间均为当前 clip 开始后的毫秒。`prepare` 始终为 0；`launch` 是发射／工具开始；`impact` 是命中或状态视觉确认；`settle` 是该 clip 结束。支援、接管和部署的 `impact` 是确认点，不是伤害。命中声音、HP 数字、状态图标必须共享同一个 `impact` 标记。

新三档为“标准”“快速”“减少动态”。标准优先读懂动作；快速用于 AI 或玩家偏好；减少动态采用替代姿态和静态提示。系统偏好减少动态时优先使用减少动态。禁用动画时立即恢复最终画面；音效独立设置仍生效，每个真实结果事件至多一次关键提示，合法反击和真实出库仍有各自的提示。批量提示可以合并，不能丢失画面或列表结果。

待机呼吸循环建议 4s、幅度不超过展示盒高度 1.5%，不同单位错开循环相位；快速保留静态待机，减少动态完全静态。选中姿态为标准 180ms／快速 80ms，减少动态瞬切并保持焦点徽记至少 100ms。受击时间包含于攻击的 impact—settle 区间，不再另加一次阻塞。

| clip 类别 | 标准 launch / impact / settle | 快速 launch / impact / settle | 减少动态 launch / impact / settle |
| --- | --- | --- | --- |
| 直射 rifle／shell／rail 普通与穿甲 | 140 / 300 / 620 | 50 / 100 / 220 | 0 / 40 / 120 |
| 导弹／鱼雷 | 180 / 480 / 760 | 65 / 140 / 260 | 0 / 40 / 160 |
| 间接 mortar／bomb／震荡 | 180 / 520 / 820 | 65 / 160 / 280 | 0 / 40 / 160 |
| 定点狙击（含准备瞄准） | 340 / 500 / 820 | 100 / 150 / 280 | 0 / 40 / 160 |
| 构筑掩体 | 120 / 430 / 620 | 40 / 130 / 220 | 0 / 40 / 120 |
| 锚定防线 | 100 / 360 / 620 | 35 / 110 / 220 | 0 / 40 / 120 |
| 主动扫描 | 100 / 380 / 640 | 35 / 115 / 220 | 0 / 40 / 120 |
| 应急修复 | 120 / 430 / 720 | 40 / 130 / 250 | 0 / 40 / 160 |
| 链路干扰 | 100 / 360 / 640 | 35 / 110 / 220 | 0 / 40 / 120 |
| 部署（impact 为显形／机装就绪） | 0 / 120 / 340 | 0 / 40 / 140 | 0 / 0 / 100 |
| 接管（impact 为归属徽记确认） | 0 / 260 / 440 | 0 / 90 / 160 | 0 / 0 / 100 |

例：标准棱镜攻击 0—140ms 架炮，140ms 发射声与炮口，140—300ms 弹道，300ms 命中声／目标受击／伤害数字，300—620ms 回稳和特效收尾。直射反击在前一发 `settle` 后开始下一条同类 clip。间接攻击不因长轨迹新增等待或反击。

致命命中从相同 `impact` 开始退场，替换普通受击尾段；在该 clip 的 `settle` 后附加标准 120ms／快速 40ms／减少动态 0ms 的退场收尾。建筑毁坏改为建筑局部破损和废墟，不套人物退场动作。双炮、连射、视觉辅弹统一绑定主 `launch` 和主 `impact`，不重复播放三个大命中声。

| 运动族 | 标准每格 | 快速每格 | 减少动态每格 | 可对齐音频的 `contact` |
| --- | --- | --- | --- | --- |
| P 步战 | 180 | 80 | 40 | 标准归一化进度 0.28／0.72；快速只 0.50；减少动态无脚步 |
| T／R 履带与炮装 | 200 | 85 | 40 | 标准／快速进度 0.50，驱动声包络而非连续新声源 |
| W／G 支援 | 170 | 75 | 40 | 进度 0.50，小机械扣合；实际发声按下方限密度规则 |
| N 舰装 | 190 | 80 | 40 | 无踏地声；段开始一次推进／水声、段结束收尾 |
| A 固定翼 | 140 | 60 | 40 | 无踏地声；段开始一次引擎、段结束收尾 |
| H 旋翼 | 170 | 75 | 40 | 无踏地声；旋翼为单段持续包络 |

每段另含标准 60ms／快速 30ms／减少动态 0ms 的收势。单次移动展示目标上限为标准 1400ms、快速 650ms、减少动态 400ms；超出时对**实际可见路径的移动间隔**统一缩短，保留每个实际转折点与海陆状态，不变更路径。长路不需要逐格新建持续声源。

海陆转换标准 100ms／快速 40ms，包含于进入新域的那一格，不叠加总时长；中点更换工作形态。减少动态到格时直接切形态。转换不得提前揭示未到达或未观察格的地形。

`contact` 与持续声的相位受动作时钟驱动。动作可以每格发出接触标记，实际可闻接触声标准最短 120ms 间隔、快速最短 160ms 间隔；多余标记稀疏丢弃，不改真实路径。减少动态不播放逐格接触音。暂停后从同一进度继续；音效文件不通过 `playbackRate` 变调赶时间。快速档选专用短尾或包络裁切；减少动态保留一次低强度命中／确认音，不出现高速连响。

## 6. 现有八主动技能的动作分镜

| 现有技能／型号 | prepare → launch → impact → settle | 图像限制与最终状态 |
| --- | --- | --- |
| 穿甲弹／棱镜 | 炮架稳定→炮口青白短光→窄穿透命中环→主炮回稳 | 护甲穿透效果不贯穿到第二个目标；伤害仅实际目标一次 |
| 震荡弹／弧光 | 支脚接地→抬炮抛射→金色低矮震荡圈→支架回收 | 不画持续地震；存活目标确实有震荡时才显示状态徽记 |
| 定点狙击／长钉 | 水平长炮就绪、目光锁定→窄直射→单目标精确火花→回稳 | 只在本回合未移动且技能成功时播放；不画远程隐形瞄准目标 |
| 构筑掩体／哨兵 | 取折叠掩体→底部展开→扣合确认→稳态守备 | 掩体留作小型状态标记，至核心状态到期；无地形修改或额外建筑 |
| 锚定防线／磐石 | 重心下降→四支撑接地→锁定扣合→炮架待命 | 状态期间脚部稳定；不播放移动。装甲加成和不能移动来自核心 |
| 主动扫描／游隼、纸鸢、望隼、天眼 | 天线／观察镜转向→局部细扇区→一次扫描确认→镜头回稳 | 扫描区域只在合法已知层绘制；新可见信息由核心视野提供，动画不找隐藏敌军 |
| 应急修复／织补 | 机械臂抬起→指向合法友军／建筑工具端→工具扣合与绿色加值→收臂 | 实际恢复值最多 40 且受上限；不显示固定 +40、不修自己、不复活 |
| 链路干扰／脉冲 | 稳定臂展开→紫色短链路→目标终端括号一次确认→盘减亮 | 目标下次己方回合 1 AP 的状态来自核心；不加入伤害、永久控制或持续瘫痪 |

驻守、伏击、防空反击是现有被动／规则能力。驻守只增加当前状态可读性；伏击可在合法攻击准备中用稳态瞄准姿态；防空反击在真实反击的 `attack` 中标记“反击”，不自造技能事件。

技能失败、目标不合法、被迷雾遮挡、冷却中或 AP 不足时不播放成功演出，仅沿用 UI 错误提示。工具连线和技能名称仅对有权看到该行动的观察者显示。

## 7. 复合事务和真实事件顺序

`Game.execute` 已经完成规则结算，再用 `before`／`after` 的合法观察结果生成视觉计划。clip 的 `impact` 是揭示结果的时机，不是第二次扣 HP 或占领的时机。整个复合事务维持 `busy`，允许暂停、静音和镜头操作，不接受重复下令。

1. **普通攻击与反击：** 攻击准备→发射→目标受击或退场→攻击收尾→仅在实际存在的合法反击时，存活目标准备／发射→攻击者受击或退场→反击收尾。间接攻击不触发反击；不能反击或次数用尽的单位不回射。攻击者被反击击毁时仍按已发生的第一发命中结果展示。
2. **攻击释放部署格：** 完成攻击与合法反击，恢复退场后的可见格状态，再播放实际自动出库。死亡角色不能与新单位在同一个格同时完整出现。
3. **移动自动占领与出库：** 沿实际可见路径移动→在真实终点收势→仅当核心记录自动占领时，人物接管／建筑归属确认→按核心事件顺序显示真实出库。源设施部署格释放可能使源设施队首出库；不能误画为占领了敌方设施后立即继承其库存，因为接管会清空原订单和库存。
4. **移动被隐藏单位阻挡：** 动作在最后实际进入格停止；不能走到请求终点再弹回，也不能画过隐藏阻挡者。零格移动只提示“路线受阻”，不播放占领或部署。
5. **手动接管：** 仅在已成功接管后播放终端／探针与徽记确认。所有单位沿用现规则可占领；航空与海军通过探针／接驳表达，不落到不合法地形、不追加移动。
6. **回合开始：** 严格尊重核心事件位置。现 `begin` 先释放旧 FIFO 库存，再完成到期生产，再尝试出库，最后发出 turn；镜头上不能先把所有新单位显形再补动画。一个设施同次结算最多释放一支实例，已占用部署格的剩余库存不播放显形。回合提示放在实际 turn 位置。
7. **批量部署：** 每个可见的新实例对应一个 clip，按事件队列顺序；同一实例手动部署与追加事件只播放一次。出库单位的 AP 标签采用核心结果，非当前行动方的自动出库可能是 0 AP，不能为展示就绪擅自加满。事件截断或老存档只对本次新生且可见实例保守补充，不能据库存或订单猜增援。
8. **失败、取消或换页：** 规则失败不播放成功 clip；暂停停留原进度；读档、重开、换页、后台清理恢复底层精灵／标签、移除临时层、结束等待。禁止把停在半空的动作写进存档。

退场中的应急灯熄灭和烟是表现，不生成已撤离单位、救援状态或新战场位置。战后是否成功救援属于背景叙事，不能让动画削弱本局损失。

### 观察限制

- 完全隐藏的行动无坐标、人物、兵种特效、语音或部署提示。音效不得先于视觉泄露隐藏敌军。
- 只看见命中目标：仅目标局部受击与合法数值；不画来源、炮口、连线，也不依据隐藏攻击者播放可识别型号的声音。
- 可见移动路段被迷雾隔断：分别显示，不连起隐藏路径；可见段首为短显形，无“从隐藏处冲来”的虚构轨迹。
- 新增状态标记不能穿透迷雾常驻。未获观察权限时使用当前信息规则，不从内部最终状态还原隐藏事件。

## 8. 画布、锚点、方向与层级合同

### 统一空间

建议棋子透明源画布 256×256；超长重炮／大型翼装可用 320×320，但仍输出相同归一化锚点。静态与每帧透明画布尺寸一致，禁止按每帧内容自动裁边造成脚底跳动。

- 地面／海面基础 `pivot=(0.50,0.84)`，对应脚底或浮力平台接地点；映射到格心的稳定接地点。航空使用同一投影接地点，身体浮在投影上方，阴影仍标定原格。
- 资源登记至少提供 `pivot`、`muzzle`、`toolTip`、`sensor`、`hitCenter`、`shadow` 与 `form`；使用 0—1 坐标，随精灵变换同步，不能从画布边缘猜炮口。
- 初始适配目标：主剪影宽不超过单格可视宽的 72%，含武装外缘不超过 88%；人物面部与主体高占展示盒约 78%。格边留白用于阵营和层级标记。
- 超长炮／机翼通过更概括的透视、缩短或收拢表达，不能靠跨到相邻格遮挡来体现长度。射程和威力由 UI 数值呈现。
- 道具、头发、待机阴影不得覆盖邻格人物脸或核心标记。炮口闪光只在局部 1 格内；弹道是独立层，可跨合法已观测空间。

当前棋盘由 `A.hexPoints(44)`、`xy`、`.46` 精灵缩放及建筑共格偏移构成。实施时建立“源画布→显示盒→格心”统一变换，同时供 `src/art.js`、`src/battle-ui.js`、`src/fx.js` 使用。建筑同格不能另临时加一个会让人物脚底漂移的魔法偏移；为共格构图定义登记位置并让攻击锚点跟随。

### 六方向

逻辑方向仍取真实相邻格向量。最低资源方案绘制朝前斜与朝后斜两种基础朝向，左右按可镜像规则生成，共四个可用视向；六邻接方向就近选视向，枪口、弹道按准确向量指向目标。上下方向不要把角色扁平拉伸或旋转成横躺。

镜像只允许人物与可对称机装，不镜像 UI、文字、阵营徽记或编号。单侧大盾、非对称机械臂和关键发饰需独立左右资源或分层重排。重炮与大型舰炮可旋转武器局部，身体轻转，不整张图旋转。朝向变化标准最多 80ms／快速 30ms，包含在准备或该格移动时间内；减少动态直接换视向。

### 图层（从底到顶）

1. 地形与格边。
2. 建筑基础与旧归属覆盖（自动占领动作前保持旧归属）。
3. 合法路径／射程；单位阴影、足迹／水波。
4. 后置机装、人物躯体／服装、头部、前置武器／盾牌；局部次序可按朝向重排。
5. 弹道、炮口与目标局部受击，受当前观察范围裁切。
6. HP／AP／层级／阵营徽记与兵种小图标；命中数值与状态提示避开人物脸。
7. 焦点、键盘可见轮廓与无绘图的交互命中区域。

临时动作层保持 `pointer-events: none`。触控目标以格子的交互区域确定，人物透明空白和跨格特效不捕获点击。隐藏／恢复沿用 `data-unit-sprite`、`data-unit-label`、`data-building-sprite`、`data-building-label` 的实例级绑定；部署中不能提前露出标签。

## 9. 手机节奏与性能目标

- 战斗不使用全屏闪白、相机强抖和一击一张立绘切入；标准只用局部一次火花和短数值。所有档位不使用频繁亮灭的旋翼、扫描和紫色干扰。
- 减少动态关闭身体上下摆、后坐平移、粒子、连续尾迹和扇形扫转，以静态准备／命中／状态徽记切换替代。变化必须能通过文字／徽记读懂。
- 空闲可见单位最多只有选中角色与视口中 3 个邻近角色有低频待机，其余使用静态帧；减少动态全部静态。平移、缩放时暂停装饰性待机。
- 一次主事务最多 2 名完整活动精灵（攻击者／目标）、1 条主弹道；普通命中装饰粒子上限 6，退场 10；同一时刻最多 2 个状态环。移动只保留最近 2 格痕迹，离镜头及隐藏段即时停止绘制。
- 使用变换／透明度更新已有图层，按族缓存预解码帧。不要每帧生成大量 DOM、重绘完整地图或重新请求立绘。图鉴 2048px 立绘不进入战斗动作缓存。
- 首批资源采用分层 keyframe／小图集混合；保留未加载时静态 Q 版和现有规则标记。进入战斗先准备本局必要型号，详情立绘按需读取。
- 暂定参考验收：选定一台中档 Android 和一台 iPhone，记录型号、系统、浏览器；静态地图平移目标 ≥30fps，动作期间第 95 百分位帧间隔 ≤33ms；与同设备 v0.9 对比卡顿、首次载入、内存和触控延迟。数值为目标，测量后调整。
- 解码内存按真实像素计算：一个 2048×2048 RGBA 图集约 16MiB；手机初期同时驻留不超过 4 个此尺寸图集等效约 64MiB，另计地图、UI 和运行开销。64MiB 是精灵缓存的起始预算，不能把压缩文件大小当内存，也不能宣称全部 38 套必然放得下。
- 每局可能拥有多型号。超过预算时保留各型号静态基础图，按视口和动作加载高帧资源，使用缓存淘汰；性能降档先删装饰特效、再降动画帧，不删 HP／AP／阵营信息。

## 11. 可执行验收

### A. 资源与小尺寸识别

1. 以本局实际棋盘最小／正常／近景缩放截取全部 38 型号，显示批准的静态与移动／发射帧；检查立绘与 Q 版发色、服装、主装备一致。
2. 不显示名称，让熟悉／不熟悉玩家各测试步战、坦克、炮装、防空、海军、侦察航空、战斗航空、轰炸航空、工程和电子战；记录混淆对。大类正确率 ≥90% 为首批目标。
3. 检查 42 工作形态每个方向的脚底／平台锚点一致；停留、受击和部署没有跳格。截图检查武装不遮邻格脸、HP／AP、兵种标记，特效透明空白不捕获点击。
4. 测试壁垒／礁盾大盾、长钉／雷砧长炮、天眼宽翼、镇海大舰的极端边界；共格建筑、地图边缘和手机小屏都能读懂。

### B. 时序与规则

5. 在确定性动作时钟记录 prepare／launch／impact／settle；核对三档表，单一 marker 触发一次，视觉与声音在同一调度时钟。手机录屏确认命中声与火花偏差目标 ≤50ms，硬件输出延迟另行记录。
6. 普通直射、导弹、间接、投弹、鱼雷、致命与非致命、目标建筑逐项；每个命中数字等于实际结果。试验双炮／连射／辅弹不重复扣血或多响。
7. 验证合法反击、防空 1.5 倍反击、反击次数用尽、炮兵／镇海／侦察／轰炸／工程不反击；镇海移动后能攻击，地面炮兵移动后没有攻击演出。
8. 分别触发八主动技能；修复接近上限只显示实际值，构筑／锚定／扫描到期姿态与状态消除，震荡与干扰按核心生效回合显示；技能失败没有成功演出。
9. 移动到空敌设施且仍有 AP→自动接管；移动 AP 用尽→不接管；移动走出己方部署格→源设施 FIFO 出库；攻击／反击释放部署格→攻击尾段后出库。
10. 回合开始包含旧库存与到期生产：检查实际事件顺序、部署格阻塞无动画、单设施同次最多一支、手动部署不重复、600 条事件截断和老存档兼容。
11. 迷雾完全隐藏／只见受击者／可见路段分隔／隐藏碰撞各测；双观战席位比对画面和声音日志，计划中无越权兵种、坐标、来源或假路径。
12. 对同一已结算事务分别正常播放、加速、减少动态、静音、关动画、暂停恢复、立即 cancel、缺资源回退；播放前后规则状态快照相同，取消后所有原精灵／标签恢复，等待 Promise 结束。

现有 `node scripts/verify-fx.js` 是后续适配时必须保留的自动回归入口；本次仅编写设计文档，没有修改效果模块，未把旧测试通过记录作为新 Q 版动作验证。需要接入后扩展 marker、资源回退、锚点和新时间表验证。

### C. 手机和性能

13. 以参考设备录制一局多型号局面，快速连续移动／攻击、平移、缩放、开关音效、切后台、读档和重开；记录首屏、解码缓存、帧间隔和触控响应，按第 9 节目标评估。
14. 开启系统减少动态，所有旋翼／待机／雷达／干扰无连续闪烁和身体抖动，信息仍能靠静态徽记与文字理解。完全静音不影响操作。
15. 连续执行 100 次复合事务和 10 次重开，临时动作节点、隐藏标签、图集缓存及音频源均回到声明边界；无一次取消留下 invisible 精灵、忙碌锁或悬空状态。

每条验收应记录资源版本、浏览器、设备、三档设置、结果和截图／日志路径。资源 QA、自动核心回归和真实手机听看测试是三个独立结论，不能相互替代。

## 12. 推荐制作与接入顺序

1. **动作样板：** 前哨、棱镜、浪锋三套基础形象先做立绘／Q 版匹配，覆盖步战、履带、海陆转换、直射、受击、退场、接管和部署；按本合同做实际棋盘组合评审。
2. **规则风险样板：** 补弧光、天幕、织补、脉冲、长钉、苍隼／远雷与潜锋；覆盖间接攻击、强化反击、支援技能、固定翼投弹以及鱼雷／陆攻表现差异。
3. **38 型号推广：** 每族轻／中／重变体保持独立剪影，完成全型号和四套海陆补充形态；复用时轴，不复制同一人物换色。
4. **性能与存档回归：** 完成本地资源路径、懒加载、缓存、三档降级和 cancel；再通过第 11 节，才能把状态由“设计稿”改为“已接入并验收”。

制作人确认方向、美术交付资源、开发做资源登记与表现适配、QA 按实际设备验收。当前不具备全部分层源图、人员产能和设备基线，因此不承诺总工期与成本；按首批样板的实际工作量估算剩余型号。
