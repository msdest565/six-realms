# 《六域：边境交锋》战役流程与剧情脚本 v0.6

日期：2026-10-08。《潮线上的命令》的完整主线对白与事件规范。七关战斗配置见[关卡设计](关卡设计-v0.6.md)，剧情背景见[剧情设计](剧情设计-v0.6.md)。本文件文本可直接进入字幕与简报界面；不依赖新增配音才能交付。

## 1. 流程、时长和事件时机

主线共23段：开场1段、每关战前/战中/战后各1段共21段、尾声1段。顺序固定，不以隐藏分支锁任何真相。C01的1分钟包含开场，C07的3分钟包含尾声；全主线阅读和镜头预算14分钟。

每段以下方场景ID去重。战前在关卡初始化、玩家首次收入之前播放；关闭后才执行第一次己方回合开始。战中在配置中的首个触发事件完成、视野重算与胜负检查之后显示；若该行动已经获胜，则先锁定战斗输入，再进入战后补播流程，不能阻止胜利或打断反击。

回合3触发发生在玩家第3己方回合开始七步结算完成、开放操作之前。多个战中触发条件同时满足时只入队一次。战中内容都是对当前任务的分析，不断言玩家已完成可选目标，所以提前胜利时同样可以补播。

战斗正常胜利或玩家选择接管后，依次播放尚未观看的MID、OUTRO，登记该关线索，保存完成方式与下一关解锁。C07再播放EPILOGUE后登记整个战役完成。敌方胜利、玩家投降或退出不自动发线索；选择接管才走接管流程。

跳过按钮表示略过当前段的逐字与镜头动画，立即展示完整文本，玩家点击继续后才标记已观看；不能把关键对白直接删掉。可以开启即时文本、打开字幕历史或在剧情回顾中重播。读档按场景ID恢复，已读段不强制再播。

## 4. 模式差异、接管和可选目标反馈

正常总部模式在OUTRO前追加一行：“参谋：核心指挥点已完成交接，各站点正在按停火约定确认。”正常全建筑模式追加：“参谋：本区所有建筑完成交接，进入战后简报。”这些只解释完成方式，不改变主线结局。

接管模式改用：“参谋：协同部队接替当前战斗，以下是共同整理的交接报告。”不播放上面的个人战术胜利行，不声称玩家亲自完成未做的动作。

每关可选目标的反馈最多一行，例如C02“程砚：这次维修让我们保住了行动能力。”仅当对应成功记录存在时显示。未完成不播放责备段，不损失线索。所有可选目标的完整定义以关卡附件为准。

总部被打成废墟时，记录提取说明改为“程砚：备用介质已经取出，设备恢复另列维修。”最终广播从协同保障的备用电台接入民网，不要求刚占领的0 HP总部即时恢复生产功能；不修改战斗快照的HP。

## 5. 触发与存档的实现约定

场景ID只有一次强制首次播放；在回顾中可无限重放，不再次发线索。开始播放时写入`pendingSceneId`，完成确认后才写入`seenSceneIds`；中途退出后从当前段继续，不假定整段已读。

线索在OUTRO确认完成后登记；下一关在OUTRO、线索与完成方式一并保存后解锁。C07还要等待EPILOGUE确认，才能显示“战役完成”。未播MID排在OUTRO之前，PROLOGUE只在首次进入C01前播，EPILOGUE只在C07战后播。

场景触发不直接删除敌军、转换单位阵营、赠送资源、清空隐藏守军、修改建筑归属或跳过反击。罗峤转变在章节间叙事层处理，不在C05进行一键红转绿。所谓开路、广播和维修交接是战后叙述，不代替地图胜利校验。

必备呈现资源：六个人物肖像、七张章节背景或地图镜头预设、一个航线图状态模板；肖像与背景可先用占位图实现。字幕和完整流程必须能在缺少配音、章节插画时运行，不把美术制作排期计入玩家阅读时长。
