# 《六域：边境交锋》单位体系与等级划分 v0.5

日期：2026-10-08。状态：设计规范。十个主体体系各有Ⅰ/Ⅱ/Ⅲ三个型号，另有8种独立特殊单位，共38种。规则以[规则总册](规则总册-v0.5.md)为准，单位数值见[单位设计](单位设计-v0.5.md)。

## 等级定义

| 型号等级 | 定位 | 取舍 |
|---|---|---|
| Ⅰ级·基础型 | 早期提供核心功能 | 低价格、低门槛，适合应急补充 |
| Ⅱ级·主力型 | 常规编队骨干 | 核心职责更高效，兼顾投入与产出 |
| Ⅲ级·强化型 | 后期高投入任务 | 防护、火力或部署能力更强，承担成本、能耗或机动代价 |

型号等级与生产设施要求对应，不是经验军衔，也不会自动升级场上部队。特殊单位仅显示设施解锁要求，不另设三个虚构型号。生产时间为独立字段buildTurns；各级不要求每项属性都增加。高级设施保留低级型号。

## 共同职责

- **陆军 / 步兵**：各级保持免能源，逐级强化地面作战和生存；占领是全部单位的通用能力。
- **陆军 / 装甲车**：轻坦、主战与重坦；装甲和火力提升，以成本或机动换取优势。
- **陆军 / 炮兵**：全序列采用间接火力，移动后不能攻击；保留近距离盲区。
- **陆军 / 陆地防空**：主动对空火力逐级增加射程与强度，地面火力较弱；拥有150%强化反击，不自动保护附近友军。
- **海军 / 船舰**：水面舰队主序列，驱逐舰和巡洋舰兼顾防空，战列舰专注远程炮击。
- **海军 / 海军陆战队**：三个等级均为免能源两栖步兵，逐级提高突击与防护。
- **海军 / 海洋防空**：专门防空舰序列，仅在海洋移动；主动对空强、对海对陆弱；拥有150%强化反击。
- **空军 / 侦察**：逐级强化视野与机动范围，保持低火力；标准局在战争迷雾下提供全军共享观察，主动扫描视野+2。
- **空军 / 战斗**：三级均能对空，地面和海洋目标伤害较弱。
- **空军 / 轰炸**：逐级强化载荷与机动范围，不能攻击空中目标。

全部38种单位都有占领能力，总部不再例外。占领本格或相邻格建筑花费1 AP并结束行动，需要先清除建筑格内的敌军。舰船可从相邻海洋格接管沿岸建筑；飞机可从空中接管。陆战队仍保留登陆与免能源优势；两栖轻坦独立提供装甲支援，反坦克步兵独立为Ⅱ级特殊单位。

陆地防空和海洋防空是专门对空序列；驱逐舰和巡洋舰保留多用途防空。防空射程表示主动攻击范围，六种专职防空反击伤害为标准伤害×1.5，每周期1次；没有对附近友军的自动拦截。战列舰仍不能对空；不能按Ⅲ级标记推断其继承所有低阶武器。

## 规模与学习方式

主体型号30种，特殊单位8种；陆军17、海军11、空军10，共38种。相较v0.2保留原21种，补充17种。天幕从工厂Ⅱ级提前至Ⅰ级，猎矛从兵营Ⅲ级提前至Ⅱ级。

单位界面先显示通用兵种，再显示代号；可按军种、体系和等级筛选，特殊单位单独分组。新型号复用体系核心规则，不为每个等级增加新的资源、弹药或主动操作。

所有军种共用一套占位：每格最多一个单位，允许单位与建筑同格。全部单位可占领本格/相邻格所有建筑，包括总部、地基与废墟，花1 AP并结束行动。两种胜利模式与技能具体边界见规则总册。

本文件是v0.5设计，不声称代码已同步；标准地图、双方回合、反击、技能和迷雾需实现后验证平衡。
