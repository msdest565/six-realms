# v0.8 美术实现说明

本轮绘制为原创 SVG，延续架空军事和六边形棋盘风格。单位数值、地形通行和建筑规则沿用 v0.7；参考经典战略游戏的清晰轮廓与地图信息层级，不使用参考游戏的图片资源。

## 地形与邻接

- 公路按实际相邻道路形成东、东南、西南、西、西北、东北六个方向的出口。连接端落在共享边中点，斜向道路、转弯、三岔路与六向交叉口均能衔接。孤立道路没有虚构的横向贯通出口。
- 海洋格填充覆盖完整六边形；海洋内部不重复描边，波纹按世界坐标连续排列。海洋与海岸之间不再叠加一条格线。
- 海岸水面只绘制在实际邻接海洋的扇区，六个方向和多个海洋方向均支持。沙滩、浅色浪线和蓝色水体共同呈现岸线；孤立海岸保持沙地外观。
- 相邻山脊通过共享边中点连接山体与高光脊线，形成连续山脉。峰顶、背光岩面和山体底色仍清楚区分不可通行的山脊。
- 河滩以浅水河道连接相邻水域，碎石与工业废墟采用不同轮廓、明暗及残垣细节。

调用 `GameArt.terrainMarkupContext(cell, cells, size = 44)` 绘制地图；`terrainContext(cells, cell)` 提供邻接方向。坐标索引使用 WeakMap 缓存，每格只读取六个相邻格，地形属性修改后会立即影响相邻关系。现有 `terrainMarkup` / `terrainSvg` 保留用于图鉴和独立资产。

## 单位

全 38 个单位、两个阵营共 76 个资产加强履带节、武器、装甲面、窗舱、传感器与配色识别。

- 步兵分为双人步枪小队、三人突击小队和前排防护盾的重步兵；反坦克步兵有肩扛发射器及稳定脚架。
- 轻型坦克、菱形炮塔主战坦克与宽履带双炮重坦形成不同体量；三种炮车的轮架、炮管和稳定支撑脚明显不同。
- 地面防空分别突出四联炮、双导弹箱和四导弹箱加雷达桅杆；工程车突出机械臂、修复十字和警示条，电子战平台突出六足、磁盘与天线，歼击车突出超长磁轨炮。
- 舰艇突出舰体宽度、炮塔数量、舰桥、烟囱及雷达系统。陆战队海上显示登陆艇，登陆后显示步兵及蓝色海军标记；两栖坦克显示浮力侧舱，潜艇显示胶囊舰体和低矮围壳。
- 侦察机突出长翼与传感器，战斗机突出后掠翼与引擎，轰炸机突出平直翼、载荷舱和多引擎，直升机突出旋翼及外挂武器。

每个单位外层含 `.unit-art.unit-{id}`，直升机旋翼含 `.unit-rotor`，供动作层使用；原 `unitMarkup` 和 `unitSvg` 参数保持兼容。

## 建筑

九类建筑使用独立材料色、立体轮廓和强化地基：总部为指挥堡垒，城市为蓝窗高楼，市场为分色篷顶，能源站为变压器与电力标志，海上能源平台为高架甲板，兵营为帐篷和训练场，工厂为锯齿屋顶及烟囱，港口为吊臂和停泊船，机场为跑道、机库和控制塔。

`buildingTileMarkup(type, side, level = 1)` 在地形上叠加全格地基色、边框与所属阵营识别条；建筑主体仍使用 `buildingMarkup`。地基无需放入主体缩放组。建筑二、三级另有扩建结构和等级标记，75 个阵营/等级资产完整导出。

## 验证

运行 `node scripts/export-assets.js` 和 `node scripts/verify-art.js`。验证包括六方向道路的双向中点一致、64 种道路组合、64 种海岸朝向组合、64 种山脊组合、海洋内部边线取消、缓存更新、38 种独立单位与九类建筑结构、完整 159 个 SVG 资产导出。结果记录于 `reports/art-tests.json`。

原文件中的 `terrainMarkup`、`unitMarkup`、`buildingMarkup` 仍可使用；规则引擎不依赖新的绘制 API。
