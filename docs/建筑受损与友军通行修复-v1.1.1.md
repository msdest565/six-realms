# v1.1.1 · 建筑受损与友军通行

更新：2026-10-10。

## 建筑受损

原规则引擎能对生产设施正常结算伤害，例如坦克攻击空置装甲工厂会使 HP 从 200 降为 150；问题在于地图未提供建筑血条，默认点击空置敌方设施还会先尝试移动占领。

- 总部、兵营、装甲工厂、军港和机场的地图标签现在同时显示结构血条和 `HP 当前/上限`。受损和低血量采用不同颜色，损毁显示零血量与“已损毁”。
- 受损建筑标签在远景和小屏幕也继续显示；悬停仍可查看完整信息。迷雾中的建筑只显示最后观测值，不泄露新的伤害。
- 选中己方单位后，默认点击射程内的敌方完好生产设施会直接攻击。显式“移动”仍可用于进入建筑并占领；中立设施、废墟及收入据点保留默认移动占领。
- 驻守单位与庇护设施继续分别结算 75% / 25% 伤害，分别显示部队和结构生命值。没有守军时，结构承担该次攻击的全部结算伤害。
- 城市、贸易站、能源站和海上能源平台仍是无结构生命值的收入据点，只能占领；展开标签明确说明这一点。

## 友军通行

- 允许经过己方或同队盟友占据的格子；只能在空闲的、地形兼容的格子结束移动，保持单格一支部队。
- 道路奖励、地形移动点、能源、累计回合移动预算和行动点仍照常结算。舰船不能借友军格穿过陆地，陆军也不能借此越过海洋或山脊。
- 可见敌军继续阻断路线。移动途中遇到隐藏敌军时，停在此前最后一个空格；不会因友军串列而重叠单位，也不会扣除未完成路段的能源或移动点。
- 经过建筑不会自动占领，经过被占用的自动部署格也不会释放仓库。仅在实际终点处理占领和自动部署。

## 验证与兼容

专项入口：`npm run test:combat-movement`；全量入口：`npm test`。新增检查覆盖所有 38 型号通行、盟友、狭窄通道、隐藏碰撞、道路与能源、建筑真实伤害及观察到的动作效果。

地图界面检查覆盖结构血条宽度、同格守军的独立血量、零血量、收入据点和迷雾缓存；真实界面控制器检查攻击后重绘、存档与动作结束后的血量一致性。这些是 Node / 模拟 DOM 检查，不代表真实浏览器布局或真人体验验收。

存档 schema、规则版本、本地存储键和原有迁移流程保持兼容。本次不接入待开发的 42 关剧情设计。
