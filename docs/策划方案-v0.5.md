# 《六域：边境交锋》策划方案 v0.5

日期：2026-10-08。状态：交付实现的完整规则基线；本轮只开发文档。版本入口为[交付索引](交付索引-v0.5.md)，全局规则为[规则总册](规则总册-v0.5.md)。无需依靠历史v0.2补全本版行为。

## 游戏方向

双阵营六边形回合制沿岸战略。玩家通过占领建筑取得收入和生产位置，用金钱招募单位、用能源移动部队。地面、海洋、空中有不同的通行与攻击职责，但所有单位都能占领建筑；每格最多一支部队，允许部队与建筑同格。

默认占领敌总部获胜，也可开局选择占领地图全部建筑获胜。总部被摧毁留下可占领废墟，不直接结束游戏。玩法以确定伤害、共享视野、兵种协同和可预测的回合结算降低学习成本。

## 单位框架

38种单位：陆军17、海军11、空军10。陆军为步兵、装甲车、炮兵、陆地防空；海军为船舰、海军陆战队、海洋防空；空军为侦察、战斗、轰炸。十个主体体系各有Ⅰ级基础、Ⅱ级主力、Ⅲ级强化，共30型号。8种特殊单位独立分组，没有虚构的三级升级链。

型号等级和设施解锁门槛保持一致，高级设施保留低级生产选项；场上单位不通过经验升型号。Ⅰ/Ⅱ型号一般1回合生产、Ⅲ型2回合。通用兵种名称优先于代号，界面统一呈现HP、装甲、伤害、射程、移动、能耗与技能。

## 数值与操作

基础步枪步兵80 HP、0装甲、固定30基础伤害。HP、装甲和伤害项采用10点步长；装甲为固定减伤，最低标准伤害10。普通单位反击为标准伤害的50%，六种专职防空反击为150%，结果允许5点步长。

每单位每个己方回合2 AP，移动花1 AP，攻击、占领、主动技能花1 AP后结束行动。整回合共享一份移动预算。工程车每个己方回合修复一次40 HP，同一目标每回合最多接受一次工程修复。炮兵移动后不能攻击，间接火力不引发反击；战列舰可移动后炮击。

## 标准局与范围

标准地图19×13、镜像开局，每方600金钱/60能源、8座Ⅰ级建筑、6个初始单位；9座中立建筑，初始全建筑目标25座。各方首次行动前也结算初始收入。战争迷雾默认开启，可开局关闭。总部局和全建筑局分别观察节奏，不设置强制回合上限。

本版定义双方轮流行动、两种胜负、统一占位、完整伤害反击、技能、建筑受损与废墟、动态建筑目标、建设升级生产、来源库存、部署、迷雾及存档规则。AI需遵守相同合法操作与观察范围，首轮先做到能合法完成对局，再验证策略质量。

## 实现安排与验证

先完成单格占位与双方回合，再完成攻击反击、占领胜负，接入技能与建筑工程，最后完成迷雾、标准地图、存档和AI。数值表保留v0.4基线，先对新增150%反击、维修次数、航空通用占领做完整对局验证，再根据数据调整。

[验收用例](验收用例-v0.5.md)给出确定输入与预期结果；本版交付时进行文档一致性核查，不声称游戏已经通过这些新用例。实现职责和当前代码基线见[实现交接说明](实现交接说明-v0.5.md)。
