# 六域：边境交锋 v0.8 开发验收报告

交付日期：2026-10-09。项目：`D:\AI\回合制战略`。本轮在已完成的 v0.7 游戏上继续开发，所有模块均为离线 HTML、CSS、JavaScript、SVG 和 Web Audio，无前端依赖或联网资源。

## 本轮交付

| 用户要求 | 已实现行为 | 主要文件 |
| --- | --- | --- |
| 简化移动与战斗 | 左键选择后直接点目的地／敌军／据点；右键直接命令；同格多个合法攻击目标才选择 | `src/controls.js`、`src/battle-ui.js` |
| 地图占满游戏窗口 | 战场占满内容视口，资源、部队、生产、建设、目标、存档和菜单放在地图内 | `battle.css`、`src/battle-ui.js` |
| WASD 与空格 | 持续平移、拖拽、指针缩放、小地图；暂停同步停止 AI、动画和声音 | `src/battle-ui.js`、`src/ui.js`、`src/fx.js` |
| 单位特征与建筑对比 | 38 种单位独立装备轮廓，九类建筑材料、地基、等级扩建和阵营标记 | `src/art.js`、`assets/` |
| 相邻地形联动 | 六方向道路与转弯交叉、连续山脊、无内部重线海面、按海洋方向绘制岸线 | `src/art.js` |
| 移动、攻击、反击与占领效果 | 五类移动及两栖切换、真实路线、武器弹道、命中、实际反击、击毁与旗帜接管 | `src/fx.js`、`fx.css` |
| 技能动作和音效 | 八种主动技能独立效果，本地合成脚步、马达、武器、爆破、雷达、修复及干扰声音 | `src/fx.js`、`fx.css` |
| 关卡与自定义人机 | 同一规则引擎下执行部署、夺点、战斗、修复、生产、能源发展与机动 | `src/ai.js` |
| 四档难度曲线 | 剧情和自由战役均可选择简单／标准／困难／地狱，重试与下一章保留难度 | `src/game.js`、`src/ai.js`、`src/ui.js` |
| 人机决策区 | 地图内显示公开阶段与说明；隐藏行动、私有威胁和候选分数经过裁剪 | `src/battle-ui.js`、`src/ai.js` |

地狱仅 AI 控制方使用生命 120%、火力 120%、护甲 110%、初始资源与收入 150%；困难保持基准数值并加强威胁、集火、安全路线与反制生产；简单使用生命／火力 85%、护甲 90%。加成覆盖预置及生产单位，预览、实际攻击和修复使用同一实例属性，存档恢复不重复加成。

游戏设置全局选择本局 AI 难度，作用于全部 AI 控制席位。剧情仍遵守有限敌方生产计划，AI 不获得额外视野或隐藏敌军数据。完整说明见[人机决策与难度](人机决策与难度-v0.8.md)。
