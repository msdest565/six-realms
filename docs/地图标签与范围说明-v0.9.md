# v0.9 地图标签与范围显示

地图名称由独立的 `#board-label-layer` 绘制在所有格子、单位图形、范围与路线之后。建筑名称不再放入单格图形组，文字不会被相邻格或六边形片段盖住。标签有背景、阵营描边和依据实际文字长度计算的宽度；选中、悬停或键盘聚焦格子可展开单位型号、名称、HP/AP、建筑别名与最后观测状态。远景缩放隐藏拥挤的普通标签，保留展开信息。标签不拦截鼠标点击。

占领模式显示单位同格与相邻六格的一格范围。当前可占领建筑以金绿色强调，不可占领建筑以赭红色标记；悬停显示原因。颜色与提示只用当前可见单位和建筑观测，隐藏守军不会改变预览，真正下令仍由统一规则引擎验证。普通单位、舰艇、两栖部队与空军均使用相同占领距离。

移动预览只检查实际目标格：若目标为可见的非己方建筑且到达后可接管，2 AP 显示“移动并占领”；1 AP 显示需下回合接管。路线中途建筑不在该预览中结算，隐藏守军不会改变预览结果。

设置生产部署格模式使用 `G.deploymentReason` 标出设施格与邻格的可设位置。占位允许设置，产出随后按 FIFO 队列等待；已配置部署位置以十字与虚线圈显示，等待时变为金色。部署位置、库存数量、在制等待详情仅显示给当前所属方或盟友，不向敌方公开。

战场菜单提供环境声独立开关，镜头变化通过可选 `onCameraChange` 回调更新音景。海面新增最多 18 条轻量高光，没有逐格 JavaScript 动画；暂停时停止高光，系统要求减少动态效果时保持静态。不会在未观测地区制造炮火或军事行动。

专项验证命令：`node scripts/verify-board-v0.9.js`。结果保存至 `reports/board-tests-v0.9.json`。该验证检查独立文字层、38 种单位的占领范围、观察权限、隐藏守军前后一致、部署与队列提示、移动占领 AP 预览、镜头回调和氛围动画边界，属于 Node 控制器/标记检查，不等同于真实浏览器排版验收。
