## 2. 试玩

直接打开 [index.html](../index.html)，或在项目目录执行：

~~~powershell
node scripts/serve.js
~~~

访问 [本机试玩](http://127.0.0.1:8877/)。已有该端口服务时刷新页面即可；代码和图片由静态服务读取。已有存档可以从“继续最近存档”或存档页面加载。

- 鼠标：选中后直接点击/右键下令；WASD移动视角，空格暂停，M/F/C/Q切换移动/攻击/接管/技能。
- 触屏/手写笔：点击合法目标显示路线、AP、能源、伤害与合法反击；确认后只提交一次。取消、拖动、缩放、切换指令和失去焦点会清理预览。远景点选先放大。
- 大厅“视听设置”或战场菜单：标准/快速/减少动态、总声音、环境、音乐、可选设备口令与六组音量。音乐在第一次用户手势后播放；总静音包含音乐与口令。
- HTTP静态服务使用本地WAV采样；file://读取采样受限时实时合成回退。没有远程字体、付费API、第三方人物或录音素材依赖。

## 4. 开发维护

~~~powershell
npm test
npm run content
node scripts/export-anime-manifests.cjs
python scripts/build-audio.py
~~~

运行游戏和Node测试无需安装前端包。重新裁切美术需要Python/Pillow：python scripts/export-anime.py。离线矢量预览 scripts/preview-anime-board.cjs 另外需要Sharp，仅用于美术检查，游戏本身不依赖它。

继续沿用原规则存档键与game-0.7规则版本，保留经济、海陆空攻击权限、自动占领、3支FIFO库存和四档AI。新表现不决定伤害、成功/失败或隐藏情报。

真实浏览器布局、设备帧率/内存、单声道与耳机听感、响度和玩家识别率尚未测量；动画是分层插值，口令是设备合成。详细限制与真机检查入口见验收记录。本次没有提交或推送Git更新。
