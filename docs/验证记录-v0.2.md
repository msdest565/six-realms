## 验证边界

file 协议导航受到浏览器工具限制，本轮没有绕过限制，也没有完成直接双击打开的浏览器实测。代码使用经典脚本和本地相对资产，无 fetch、模块导入或 CDN；直接打开为项目设计支持方式，实际验收使用本地 HTTP。

完整敌方回合、AI、占领、建筑耐久与破坏、反击、技能、战争迷雾、胜负、存档尚未实现；未做完整对局平衡与全设备兼容性验收。此记录仅对应已实现的设计试验功能。
