小队暂名“晨潮接线组”。五人先后加入跨域行动，分别承担街区联络、装甲破阵、炮位压制、海陆接驳和航空护航。她们的共同目标是让六域的最低供给实际运作起来；每个人也有故乡、家人、工作习惯和不愿轻易承认的困难。

五人是唯一人物，“前哨”“棱镜”“弧光”等仍是普通机装型号。精英姓名对应独立角色档案，不能经兵营或工厂重复生产出多个同一个人。她们使用现有战术体系的个人定制机装，普通单位继续承担规模、专业防空、侦察、修复和经济优势。

### 年龄与现有世界观的衔接

既有38型号的代表形象继续为成年女性。本次新增精英允许明确的12/18/25/30/35岁差异，其中小禾确为未成年人；年龄不等于兵种Ⅰ/Ⅱ/Ⅲ级，也不等于战术养成等级。

新增设定建议：五人属于具有个人长期档案的星芯个体，年龄指连续社会生活的年数，外形和身份与之相符。小禾使用民用成长型躯体，身体整备随真实成长更新；训练升级不会让她突然长大。她原本承担街区联络与设施接线，晶潮危机使她进入由成年队员协作保障的行动组。其能力来源是定制机装、训练和协作，而非年龄小就拥有超自然力量。

栖云可以明确是一位母亲：她收养了9岁的人类孩子“阿澄”，孩子留在镜原由亲属照顾。她同时是经验丰富的飞行员，有自己的兴趣、判断与职业责任。母亲气质通过待人方式、神态和行动表现。

**角色印象：**一个把街区路线记得很清楚的小女孩。她知道哪扇窗里有人等检修，也会在出发前把信号灯擦干净。

## 4. Lv1主动、Lv3光环、Lv5大招

主动和大招至少需要1 AP，成功后本人剩余AP归零。专属技能取代普通机型主动技。光环自动生效，不占AP、不耗能源、没有冷却。大招是每关一次的战术资源：开局充能0，首次所属回合开始仍为0，从第二次所属回合开始每次+25；主动成功+20，普通攻击每所属回合最多+10（反击和多目标附加命中不加）。充能上限100，释放扣100并标记本关已用，不因读档、退场或剧情补满。

### 结算与预览必须一致

1. 检查角色有效等级、AP、冷却/充能、能源、观测、距离、目标权限、射线与移动后禁射；失败原子拒绝，不扣资源、不充能。有限多目标由玩家确认预览清单：先选主目标，附加目标/受益者按距离、q、r、实例ID稳定排序，允许选择更少但不能超过上限；授益技能允许选择本人。
2. 以施放前状态锁定全部合法目标和输出属性。原始火力=(基础伤害+类别加值+目标域加值+光环/技能火力加值)×本次倍率×难度伤害倍率，整数四舍五入后扣有效装甲、地形与普通临时减伤，标准伤害最低10；附加目标不继承仅主目标的加值。基础值不随机抽20–40，不按10取整。
3. 完好同格己方总部/生产设施先分担25%标准伤害，按当前规则的舍入与剩余结构HP上限；再由单位个人护盾吸收单位份额。单位HP损失可以为0，结构损失不被个人护盾吸收。附加护盾表示机装的临时防护预算（防护板、减震结构与救援保护），彩色光环为界面表现；盾是单一池：新值与当前剩余值取高者；同值只延长到较晚到期，不相加。
4. 护盾授予先于本次反击，治疗上限为实际最大HP，不治疗建筑、不复活。护甲忽略在光环/主动增益与临时减甲合成后处理。相同技能ID光环取高值，不同技能ID加值可以相加；同名能源折扣取最大，非零每格最低1，原本0保持0。
5. 先完成全部命中及存活目标减甲，再按稳定排序执行所有存活直射目标的合法反击；每名守方使用自己现有的一次额度，攻击者退场后后续反击停止。反击乘0.5或专职防空1.5，在结构分伤和扣盾之前完成；间接攻击不触发反击。所有出射命中已在施放时确定，不因较早反击而漏掉后续命中。
6. 守军与同格结构作为一份命中结算，不重复作为两个溅射目标。群攻不能通过攻击建筑绕过航空守军权限；本版群攻主动主目标均为单位，普攻仍允许合法结构目标。全部事务后重算光环、视野、生产/部署与胜负，再播放动画/剧情。
7. 临时观察点不占单位/人口、不占领，不攻击；除信标因小禾退场立即撤销外，已授予状态维持至原到期，施放方出局清除。实时光环在角色退场、移出范围或变更阵营后即撤销。保存记录拥有者、施放回合和到期回合，渲染不推进时钟。
