# 《六域：边境交锋》战役验收与实现交接 v0.6

日期：2026-10-08。交付范围：七关架空历史短篇战役的剧情、关卡、时间预算和设计数据。游戏代码由用户指定的另一位agent实现。本文件的用例是预期结果，除最后的文档核查外，未声称已在游戏中执行。

## 1. 实现输入与版本职责

从[交付索引v0.6](交付索引-v0.6.md)进入，先读[战役规则与时长控制](战役规则与时长控制-v0.6.md)，再读[关卡设计](关卡设计-v0.6.md)和[剧情脚本](战役流程与剧情脚本-v0.6.md)。v0.6是战役层，v0.5继续定义单位、伤害、占领、反击、经济与基础存档。

设计附件[战役关卡配置](战役关卡配置-v0.6.json)给出7个关卡、47个建筑实例、82个初始单位实例；这些数量跨关累计，不是同一个战场同时放置。7张SVG审核图显示全部初始布局，不能直接成为开启迷雾时的玩家视图。

附件`designOnly=true`，不是现有游戏已经可以加载的运行模块。需要适配加载器、规则设置、事件与界面；不应把JSON加入目录后就报告“战役完成”。文档作者本轮未修改src、scripts、index.html、样式或游戏SVG资产。

## 2. 设计附件字段约定

| 字段 | 含义与处理 |
|---|---|
| campaignId / schemaVersion / baseRulesVersion | 战役TIDELINE、战役设计结构版本0.6、基础战斗版本0.5分别保存 |
| coordinateSystem / size | 轴坐标q等于列，r等于行；地图边界是每行同样轴坐标范围的平行四边形 |
| terrainRules | 从荒原开始依次覆盖；positions是具体格，where条件同时满足才覆盖；water为浅河 |
| buildings.key / units.key | 本关内ID后缀，加载为“关卡ID-后缀”；不能在不同关之间共用可变实例 |
| originalHQKeys / aiPolicy.hqGuardUnitKey | 都引用本关ID后缀，加载时统一补关卡前缀 |
| plan.facility / optionalGoal.buildingKey | 同样引用本关建筑后缀，不按类型查找同类全部建筑 |
| recommendedPlayerHQGuardUnitKey | 己方初始守军的本关后缀，供教学提示；不是不可调动的英雄 |
| scenes | 全战役唯一场景ID，已经含关卡前缀，不重复拼接 |
| hp省略 | 使用v0.5单位/建筑满HP；显式0建筑HP为废墟，不删除实例 |
| initialResources | 第一次收入之前；7关双方初始完好收入均为60金钱、4能源，C02中立城市废墟不产收入 |
| playerProductionWhitelist | 玩家本关补给授权，另检查设施类型/等级；不是修改单位门槛 |
| authorizationCeilings | 设施允许升级到的最高等级，不凭空生成设施，不给未授权型号生产权限 |
| enemyProductionPlan | 每条一次、有限、要付费和等待；记录未提交/已提交/已取消状态，读档不重复下单 |
| midTrigger | 成功己方事件或玩家第3己方回合，任一满足只播放一次；终局前未播则战后补播 |
| clue / nextMission / prerequisite | 战后段确认后领取线索并保存，再解锁下一关；七关无分支缺口 |
| optionalGoal | 只给本关纪念章；接管完成不授予战术章；不影响完整剧情 |
| budget / targetRounds | 时长与轮数调优目标，不能成为自动失败判据 |

补给清单引用现有38个单位id，不复制一套更低HP的“剧情单位”。长钉、电子战底盘的近现代文案覆写只用于显示，不改武器计算。总部剧情副标题保留总部类型、数值和原始实例身份。

## 3. 建议实现顺序

1. 在已验收的v0.5战斗上加情境设置和关卡加载，先复建C01—C03，确认出生占位与两种模式。
2. 接入战役外层进度、场景队列、线索与单关重试，完成“战前→战斗→补播MID→战后→下一关”的闭环。
3. 加入C04—C07的迷雾和有限生产计划，保持AI与玩家同样的信息、费用和部署检查。
4. 接入参谋建议、接管、快速敌方动画与150分钟剩余主线提示；记录接管完成与战术胜利的区别。
5. 在完整流程跑通后补肖像、章节背景、广播镜头与字幕排版；缺图缺配音不阻断剧情。
6. 新玩家实测两种模式的逐关耗时，按预算调地图/敌补兵/文本，最后执行回归验收。

战役模式设置单独命名，不能用全局关闭建设来影响标准对局。关卡切换只替换场景状态，不静默改v0.5单位常量。存档必须同时包含战斗快照和战役场景队列，避免结算成功但剧情/进度未保存。

## 5. 三小时体验验收

| ID | 检查 | 达成要求 |
|---|---|---|
| TIME-01 | 预算计算 | 总部122+14+7=143；全建筑136+14+7=157；加重试12和缓冲11=180 |
| TIME-02 | 主线文本及转场 | 23段强制正文加完成方式短句不超过3200中文可见字符；没有强制长驻留字幕 |
| TIME-03 | 新玩家首次流程 | 两种模式分别记录逐关有效时间、重试和帮助；报告中位数及慢速样本，不用熟练速通代替 |
| TIME-04 | 接管剩余流程 | 从任意关150分钟提示后选择主线推进，剩余完整剧情+转场可在30分钟内结束 |
| TIME-05 | 全建筑残局 | 不存在不可到达/不登记的最后建筑，不强制追杀逃兵，敌方有限计划不会无限延长 |

时间目标未达成时优先调整关卡配置，不删主线段、不锁另一胜利模式、不修改防空150%或工程车约定来掩盖耗时。
