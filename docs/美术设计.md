# 美术设计与资产规范 v0.1

> 历史草案。当前三军、步兵与建筑美术规范见 [v0.2](美术设计-v0.2.md)。

## 推荐方向

**俯视工业科幻，简化体块，少量发光。** 地图是清晰的尖顶六边形棋盘，单位是能在约 48px 大小读懂的机械轮廓。界面采用深青黑色、暖白文字和青绿强调，珊瑚红仅用于敌军与危险。整体像战术指挥台，但正文保持中文可读，不把装饰性英文编码当作操作说明。

推荐使用 SVG 完成棋盘、单位、建筑与 UI；概念图用于气氛和方向，不替代正式精灵资产。SVG 资产可以按尺寸无损导出 PNG。当前制作的单位与地形均有可编辑源代码和独立导出文件。

## 镜头与比例

- 正式棋盘：近俯视、无透视缩短；地块平面一致，单位顶视略展示侧面厚度。
- 尖顶六边形边长 44px，约 76×88px；实际 UI 可缩放。
- 单位 SVG viewBox 为 `0 0 100 100`，主要体块控制在 14–86 范围，炮管可至 y=8；棋盘上绘制约 56×56px。
- 所有单位默认朝上（炮口 y 负方向）；旋转只是表现，不影响攻击或装甲规则。
- 建筑底座不能盖住六边形边界，单位站在设施上时用小徽章提示设施，不重叠大图。

## 地形与建筑

荒原以低密度颗粒表现；道路为浅灰中心通道；碎石用离散低岩块；废墟用几块不同高度的破损墙体；浅滩用波纹与小发光带；山脊用高对比三角岩峰。山脊与碎石必须从轮廓区分，不能只靠色差。

核心：高矩形主体、圆形能源井、阵营旗号。节点：三臂中继柱、金色圆环，可见所属徽记。组装站：开口车库、齿形侧墙、生产灯。建筑示例由 `src/art.js` 提供；正式版需要额外导出与占领状态。

使用内置 imagegen，未使用 CLI / API 回退；最终提示词保存在 `assets/concept/prompt.txt`，生成记录见同目录 `generation.md`。页面同时保留 SVG 预览用于概念图缺失时显示。

## 动画与反馈规格（后续可玩版）

| 动画 | 时长 | 内容 |
|---|---|---|
| 选中 | 120ms | 轮廓变亮、面板更新 |
| 移动 | 每格 120–170ms | 平滑转向、低幅尘土 |
| 直射 | 250–350ms | 炮口闪光、弹道、冲击 |
| 间接炮击 | 500–650ms | 弧线弹道与落点圆环 |
| 修复 | 450ms | 细线扫描、青绿粒子 |
| 占领 | 500ms | 中立徽记切换至阵营 |
| 击毁 | 450–600ms | 局部碎片与暗化，随后移除 |

不使用大幅相机震动。尊重 `prefers-reduced-motion`，减少动画时直接跳到终点并保留信息提示。音效与动效分别可以关闭。

## 资产清单与命名

当前已提供：`assets/units/{unit}-{union|red}.svg` 共 16 个；`assets/terrain/{plain|road|rubble|ruins|water|ridge}.svg` 共 6 个。由 `node scripts/export-assets.js` 生成，实际项目和导出图使用同一套绘制函数。

## 美术验收

在 48px 单位尺寸下隐藏名称，仍应区分 6 种首发单位；灰度模式下可以依靠轮廓与徽记区分敌我；HP、AP 与设施徽记不遮住炮口 / 天线；地形叠加移动范围后仍能辨认；1280×720 下操作面板不用横向滚动；概念图与正式棋盘的用途明确。
