# 《六域：边境交锋》策划方案 v0.1

> 历史草案。当前方案见 [v0.2](策划方案-v0.2.md)，经济、兵种与攻击权限以新版为准。

日期：2026-10-08。阶段：设计提案。名称、背景、美术方向与数值可以在第一轮体验后调整。

## 1. 一句话定位

在一颗被遗弃的工业星球上，指挥一支装甲小队，利用六边形地形和互补兵种争夺能源节点，压制对手并摧毁指挥核心。

面向喜欢轻量战棋的玩家；桌面浏览器优先；鼠标操作，无实时反应要求；标准对局目标 20–30 分钟、约 12–18 个轮次。参考《星球突击队》系列页面中可确认的轮流行动与装甲作战。保留易懂的操作和短局节奏，新增深度主要来自路线、地形、兵种协同。

## 2. 设计支柱与复杂度边界

1. **六个方向，每步都有选择。** 邻接距离统一，不区分正走与斜走；道路、掩体和山脊创造绕行与占位。
2. **先看结果，再下命令。** 首版使用确定性伤害，显示路径、射程、视线和伤害组成；攻击预览包含反击。
3. **单位互补。** 侦察、夺点、正面装甲、反装甲、间接火力、修复，各有位置。
4. **一张地图，一个资源。** 只有能源，不增加弹药、能源、独立科技树、英雄养成或复杂生产链。

首发同构阵营、6 种单位、6 种地形、3 类建筑。8 种单位完成设计，重坦与电子战留待首版验证后加入。首发不增加朝向装甲、空军、海军、高低层级或单位升级。单位面向只是动画表现。

## 3. 世界与阵营

工业星球「赫利俄斯-6」的殖民政府撤离后，维护设施失去统一控制。两支自治防卫网络争夺维持城市运转的能源：

- **远征联合 / 联合军（青绿，圆环徽记）**：救援与勘测设备改造为军用平台；浅灰装甲、青绿信号灯。
- **赤岩防卫 / 防卫军（珊瑚红，三角徽记）**：工业采掘与防卫网络；深灰装甲、红色识别板。

双方初期使用完全相同的规则和数值，以颜色、徽记、称呼区分；阵营非善恶二分。美术避免直接复制参考作品的轮廓或界面。

## 4. 核心循环

观察战场 → 规划夺点与掩护 → 移动 / 攻击 / 支援 → 占领设施 → 用能源招募 → 结束己方回合 → 敌方行动 → 下一轮。

「玩家回合」是一方的行动时段；「轮次」是双方各完成一个回合。所有单位均可自由选择激活顺序。

### 回合与行动

- 己方回合开始：结算能源与节点得分、部署上轮招募、刷新全体己方单位为 2 AP、重置反击、技能冷却减 1。
- 每次移动花 1 AP，最多走完一个移动预算；可以连续移动两次。
- 普通攻击花 1 AP，随后剩余 AP 归零。每个回合最多攻击一次；可以移动后攻击，攻击后不能再移动。
- 占领、修复、架设、干扰花 1 AP，执行后 AP 归零。技能与普通攻击互斥。
- 等待使单位剩余 AP 归零。结束回合前若有单位仍可行动，显示列表，玩家可选择继续或确认结束。
- 移动命令未发现新敌人且未触发任何信息变化时，可以立即撤销最后一次移动；战斗、占领和技能不可撤销。正式版再实现撤销，本次试验台仅提供场景恢复。

## 5. 六边形地图与地形

使用尖顶六边形，轴坐标 `(q,r)`；第三坐标 `s=-q-r`。距离为 `max(|dq|, |dr|, |dq+dr|)`。六个邻居为 `(1,0),(1,-1),(0,-1),(-1,0),(-1,1),(0,1)`。

标准地图 13 列 × 9 行，共 117 格；教程 9×7；大地图最多 17×13。显示采用错列行布局，数据保存轴坐标；当前地图上半部奇数行右移、下半部奇数行左移，使格位与地形围绕中心 `(4,4)` 真正旋转对称。每格只能容纳一个单位；建筑可与一个单位共格。任何单位占用的格子均不能通过或落脚，不设置控制区规则。

| 地形 | 进入消耗 | 防御减伤 | 视线 | 战术作用 |
|---|---:|---:|---|---|
| 荒原 | 1 | 0 | 不遮挡 | 常规推进 |
| 道路 | 1 | 0 | 不遮挡 | 在一次移动内全程进入道路时，额外 +1 移动预算 |
| 碎石 | 2 | 1 | 不遮挡 | 低速推进换取少量保护 |
| 工业废墟 | 2 | 2 | 遮挡经过的射线 | 轻型单位的安全占位 |
| 能源浅滩 | 2 | 0 | 不遮挡 | 分割路线；游隼进入仅消耗 1 |
| 山脊 | 不可进入 | — | 遮挡经过的射线 | 形成通道与炮击死角 |

防御对所有单位和伤害都有效；废墟本身不是建筑。道路奖励判定依据完整路径，不只看目的地；在道路与非道路之间切换后本次移动仅有基础预算。起始格不计进入消耗。

### 视线、迷雾与攻击

- 首个开发里程碑公开地图；最终首发开启「探索过的地形保留，敌人只在当前视野内显示」的战争迷雾，并提供开关。
- 每个单位视野是其视野半径内且具有视线的格子。山脊和废墟阻挡中间格，起点 / 目标格不阻挡；可以看见阻挡格本身。
- 射线恰好穿过两格边界时，只要任意一条相邻射线通畅，判定可见。客户端和 AI 必须共用相同算法。
- 直射需要目标可见、距离在射程内、射线通畅。弧光可以越过遮挡，但目标必须由任意友军实际看见；不允许盲射或攻击迷雾内旧位置。
- 六边形距离包含最小射程。弧光射程 2–4，相邻目标不能攻击；其他武器从 1 格起。
- 试验台关闭迷雾、保留直射视线规则；技能与弧光的静止限制留待可玩版实现。

## 6. 战斗与反击

全部数值为初始平衡值。确定性伤害：

`伤害 = max(1, 武器基础伤害 + 对目标类别的加成 - 目标装甲 - 目标地形减伤)`

单位类别仅分「轻型 / 装甲」。当前生命不影响攻击伤害，生命降到 0 立即移除。非溅射武器一次只命中一格。建筑使用装甲类别；普通攻击可以摧毁基地。

被直射命中的目标若存活、攻击者在它的直射射程内且视线通畅，则自动反击一次，伤害向下取整为普通伤害的一半（至少 1）。每个单位从自己的回合开始到下一个自己回合开始，最多反击一次。反击不消耗 AP；反击不能触发二次反击。间接炮击和电子干扰不会受到反击。弧光、织补和建筑不能反击。

正式游戏显示「造成 X / 预计反击 Y / 双方剩余 HP」；试验台只计算和执行单次攻击，明确显示反击未实现。特殊技能不进入普通攻击公式，按各自说明结算。

示例：棱镜对废墟中的长钉攻击，`5+1-2-2=2` 点伤害；在荒原则为 4。游隼在荒原攻击棱镜，`3+0-2-0=1`。长钉攻击荒原棱镜，`5+3-2=6`。由此体现兵种与位置的双重价值。

## 7. 设施、能源与招募

| 建筑 | 规则 |
|---|---|
| 指挥核心 | 每方 1 座，24 HP、装甲 2，不可占领；每个己方回合 +60 能源；被摧毁立即落败 |
| 能源节点 | 地图中立 3 座，不可摧毁；己方回合开始每座 +20 能源、+1 信号分；无需驻守 |
| 组装站 | 每方初始 1 座，地图可配置中立站；不可摧毁；所有者可以排队招募 |

能源初始 240、上限 600；地图初始军队不从这 240 中扣费。游隼、哨兵、织补、脉冲可站在节点 / 组装站上使用「占领」，花 1 AP 并结束行动，立刻改变归属；无多回合占领进度。不可占领己方设施。每回合开头结算一次，夺点不立刻发放收益。

每座组装站最多一个生产槽；招募立即扣费，在下一个己方回合开始部署到站点或其邻格的空格，由玩家选择。如果无合法空格，订单等待而不丢失。被敌方占领时取消原方订单并退还原方已付能源（不超过上限）；订单不会转移。每方最多 12 个存活单位，排队订单也计入上限。首发不允许取消订单来重复刷收益。

### 胜负与防拖延

满足任一条件即获胜：摧毁敌方指挥核心；己方回合开始结算后达到 15 信号分且领先对方至少 3 分。

第 20 轮结束双方尚未胜出时依次比较：信号分、存活单位的成本总和、核心剩余 HP；全部相同则平局。一方失去全部单位，但有核心与待部署订单 / 足够能源和己方组装站，仍可继续；两者皆无则败北。玩家可随时投降。

## 8. 初始地图「裂谷中继站」

13×9，180° 对称的地形与建筑；左右基地各距中心约 6 步；三条路分别强调速度、掩体和火力。

- 上路：废墟群与短路，适合轻型侦察、夺点、支援。
- 中路：中立节点、开放交叉火力区，主战坦克争夺通道。
- 下路：浅滩与山脊，迫使绕行，适合反装甲伏击和炮兵配合。
- 三个能源节点分布在上、中、下，每个都有至少两条可达路线。可玩版须检查中心首达时间、部署距离和先手优势，必要时给后手初始 +20 能源。

正式初始编制：每方游隼×1、哨兵×2、棱镜×1、长钉×1、织补×1。弧光在组装站招募。设计工作台的场景是展示布局，与正式开局编制不同。

## 9. 教程与单人内容

首发包含 3 个教程和 1 张遭遇战地图：

1. **接管信标（5–8 分钟）**：2 种单位、道路与荒原、移动和占领，敌军不招募。
2. **废墟中的视线（8–12 分钟）**：加入反击、视线、装甲和修复，击败固定守军。
3. **越过山脊（10–15 分钟）**：加入弧光、最小射程、组装站和资源，摧毁核心。
4. **裂谷中继站**：完整遭遇战，难度「入门 / 标准」。入门 AI 降低集中火力偏好，不读取玩家未公开的位置；不通过暗改命中率制造难度。

AI 按「防止核心被毁 → 可击杀敌军 → 控点与收益 → 支援伤员 → 保持火力覆盖」评分候选命令。与玩家共享合法行动校验和有限视野；加种子用于复现对局。先实现规则 AI，后调整权重。

## 10. 操作与界面

左键选单位 / 格子；动作面板选移动、攻击、技能、占领、等待；第二次明确点击目标后执行。移动和攻击预览用不同轮廓与图案区分，不能只靠颜色。右键或 Esc 取消当前模式；M / A 切换模式、空格下一名可行动单位、Enter 请求结束回合。移动端首发支持查看和基本点按，后续再优化拖动与手势。

顶部：阵营、轮次、能源、节点数、信号分。中央：地图与图层按钮。右侧：单位详情 / 目标预览。底部：动作、回合按钮、事件日志。未探索格深色，已探索未可见格降低亮度；HP 和 AP 不遮住轮廓；被击毁单位从棋盘消失并记入日志。

音效用轻电子 / 机械风格；移动、选中、攻击、修复各一个短音；音乐可关闭，首次用户操作后才初始化浏览器音频。默认无屏幕强闪，支持减少动态效果。

## 11. 技术方案与当前交付

当前用 HTML + CSS + 原生 JavaScript + SVG，不依赖框架 / CDN / 模块加载 / fetch，可从 `file://` 运行。设计数值与地图绘制分离；规则函数不依赖 DOM。SVG 图形便于缩放、改色并导出独立资产。

可玩版延续数据驱动架构：`GameState → 合法命令 → 状态更新 → 事件 → 渲染`；存档为带 schemaVersion 的 JSON，正式版用 localStorage 自动保存并允许导出。新增地图也从本地脚本导入，保留双击运行体验；资源量增大后再考虑打包工具。

当前已实现：设计工作台、8 种单位数据与绘图、6 种地形、六边形距离与寻路、道路奖励、浅滩机动、视线、直射 / 间接射程、单次确定伤害、移动 / 攻击 / 行动点示范。未实现：完整回合、反击、技能、弧光静止校验、占领、建筑战斗、经济、招募、AI、迷雾、存档、胜负。

## 12. 分阶段开发与验收

| 阶段 | 交付 | 验收 |
|---|---|---|
| D0 策划与视觉（本次） | 方案、单位、美术规范、离线工作台 | 能浏览所有设计与进行六边形规则演示 |
| D1 基础对战 | 双方本地轮流、6 单位、HP / AP / 反击、核心胜负 | 从开局完成一局，命令非法时不能改状态 |
| D2 战略闭环 | 占领、招募、经济、单位技能、视野 / 迷雾 | 生产阻塞、占站取消、结算时序与存档均正确 |
| D3 单人首发 | AI、3 教程、1 地图、动效音效 | AI 无视野作弊；普通局 20–30 分钟；刷新可继续 |
| D4 扩展 | 重坦、电子战、更多地图 | 仅在 6 单位版本平衡后纳入 |

平衡观测：先手胜率目标 45–55%；无单一兵种成为所有开局的必买；每单位至少有一种有效应对；同水平玩家能够形成至少两条可行夺点路线。收集 20–30 局记录后再改数值，不能把当前草案称为已平衡。

技术验收：双击离线加载无报错；地图 117 格正常显示；计算与 UI 使用同一份单位数据；缩放后选格正确；邻接、不可达、遮挡、最小射程、濒死反击、能源上限、胜利优先级均有检查。目标普通桌面浏览器交互即时，AI 一次回合不超过 2 秒（开发阶段实测）。

## 13. 下一轮需要确认的方向

当前默认科幻地面装甲、同构双方、确定性伤害和轻中度复杂度。第一轮浏览后优先反馈：是否更希望贴近某代原作；是否喜欢当前俯视工业科幻画风；是否接受「核心 / 节点」双胜利路线。反馈不会阻止本次方案交付。
