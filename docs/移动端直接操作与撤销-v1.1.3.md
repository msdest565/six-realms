# 移动端直接操作与撤销 · v1.1.3

更新：2026-10-10。原生静态网页，无新增构建步骤。运行仍为七章战役；42关设计待接入。本版替代 v1.1.2 的触屏预览确认和底部单位面板。

## 操作

- 点己方部队选中，再点空格移动、敌军攻击。空置建筑可到达时优先进入；终点剩余至少1 AP自动占领，已在建筑格时再点该格占领。无法到达但在射程内的敌方设施可以直接攻击。鼠标桌面沿用原有默认攻击优先规则。
- 单指拖动、双指缩放、0.65秒长按情报。拖动、长按、双指后的抬手和取消都不会下令。远景点格也直接执行，不再要求放大后重复点选。
- 右侧：各技能专属图标、生产、升级、废墟重建、详情、撤销、取消选择。取消选择按钮也退出技能/配置状态。基础移动、攻击、占领不设手机按钮。
- 自身技能点图标立即执行；指向技能点图标后，再点地图目标。同格有多个合法修复对象时，用目标头像/设施图标选择一次。
- 左侧：部队、建设、目标、记录、帮助。顶部：资金、能源、轮次、暂停、菜单。底部：下一部队、小地图、结束回合。主图标40px，SVG图案24px；按钮有辅助阅读名称，鼠标悬停1.5秒、手机长按0.65秒解释。
- 单位/设施属性只在详情弹窗中展开。点X或弹窗外关闭；弹窗打开期间，地图点击不会下令。剧情必须确认阅读，点击外部不会跳过剧情。
- 生产图标打开头像列表，显示型号、等级、成本和耗时；点可用型号直接下单，资金/等级不足则禁用并提供解释。弹窗底部用部署准星配置自动部署格，订单可用X取消，仓库用一行头像与数量显示。仍保持单槽订单、每设施3支FIFO、空格自动出库。
- 提示在屏幕下沿，模式提示在左下；AI状态只显示边缘活动标记。横竖屏、安全区域、小地图和弹窗均保留滚动与避让。切后台保存并暂停，返回需手动继续。

## 移动撤销

- 撤销本回合最近的连续移动，倒序逐次恢复。选中其他部队、浏览详情或拖动地图不清空记录。
- 恢复单位位置、AP、累计移动预算、道路加成、移动状态、能源、统计、事件、日志及关联建筑状态。自动占领导致的归属/订单/仓库变更、移开部署格触发的自动出库也一并恢复，不会叠格或重复发兵。
- 保留新探明地形、发现的阻挡敌军和已知建筑情报；游玩计时不回退。撤销后增加revision并重新计算视野，自动保存可通过原存档校验。
- 成功攻击、技能、生产、升级、设施配置等其他事务，回合交接、触发剧情、战斗结束、读档或刷新会清空记录。非法指令不清空。动作播放和暂停时不能撤销。
- 历史只保留在当前页面内，最多48次（24支部队×每回合2 AP），不扩展存档格式。旧存档仍使用`game-0.7`、`0.7`、`six-realms-v0.7`，不改地图哈希或重发收入。

## 实现入口与验证

`src/mobile-battle.js`负责手机HUD和设施弹窗，`src/icons.js`负责SVG图标，`src/move-undo.js`负责移动事务恢复；`src/ui.js`接入保存/命令，`src/battle-ui.js`保留桌面与共用棋盘，`src/controls.js`处理默认指令。

`npm run test:mobile-actions`：19/19组直接操作/撤销检查；`test:mobile`：33/33组、七种视口的控制器/手势/CSS/资源约束。相关规则、生产、界面、AI、视听回归合计390/390检查、8场难度对局、618条静态资源路径有效。汇总：`reports/mobile-direct-release-v1.1.3.json`。

验证使用真实运行模块及隔离VM/模拟DOM，不代表浏览器排版、触屏硬件、FPS或真人听感验收。已保存的浏览器访问权限阻止本地预览，本次未绕过该限制。TapTap安装包、SDK和提审仍未完成。
