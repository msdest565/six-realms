# 《六域：边境交锋》美术与规则信息设计 v0.5

日期：2026-10-08。状态：设计规范。既有v0.4素材基线为38型号×2阵营=76单位SVG、8地形SVG、75建筑SVG，共159个；数量为历史资产清单，本版未重新导出或新增素材。

## 单位识别

主体体系用一至三条等级标记表示Ⅰ/Ⅱ/Ⅲ，特殊单位不画型号等级条。名字先显示通用兵种，再显示代号。步兵靠编队与护甲，炮兵靠轮架、履带、炮管与支架，专职防空靠雷达和导弹箱区分。防空舰以雷达和导弹阵列区别于主炮舰。

侦察机突出观察装置，战斗机突出后掠翼与发动机，轰炸机突出平直翼和发动机阵列。陆战队海洋状态显示登陆艇，陆地显示步兵；两栖轻坦保留浮力侧舱。潜艇没有第二层或隐身占位图标。

联合军为青绿圆环，防卫军为珊瑚红三角；颜色之外保留阵营形状，方便辨认。单位资产继续使用100×100透明SVG，无外部图像依赖。

## 单格单位与建筑

每格只有一个单位主图标；取消地表单位和飞机共格、另一图层单位缩略标记与切换选择。空军仍画飞行符号、阴影及“空中”状态，但不能用阴影暗示下方允许另一支单位。

单位与建筑可以同格：建筑作底图，单位图标作前景；选中信息区明确给出单位和建筑两个入口。攻击同格目标必须显示选择项与目标名称，避免误伤建筑。军种或目标状态过滤只影响显示，不改变占位和规则。

建筑完好、受损、废墟和在建地基使用不同状态标志。废墟保留建筑类型、等级与阵营归属，附“功能停用、仍可占领”的提示；不要只显示一堆无法判断目标身份的碎石。

## 行动反馈

专职防空卡显示“反击150%｜剩余0/1”，范围高亮标为“主动攻击射程”，不展示自动保护圈。工程车显示“修复40 HP｜本回合剩余0/1”，目标已接受工程修复时标记原因。技能显示剩余冷却与精确效果到期时间。

移动预览同时显示路径、累计移动点和能耗；所有占位格按同一规则拒绝停留，未知敌军不能提前泄露。攻击预览显示伤害、预计反击、双方最终HP；普通最低伤害10与反击倍率清晰区分。

顶部固定显示胜利模式、轮数、行动方、资源及建筑占领进度。终局显示获胜原因与目标建筑，锁定操作。全部建筑模式应能筛选当前已知未控制建筑，失去视野的信息明确标“上次观察”。

## 教程和阅读负担

规则教学先讲单格占位、2 AP、攻击结束行动和通用占领，再讲兵种差异。目录以三军→体系→三级排列，特殊单位独立一栏；每张卡只突出其核心差异，计算细节在展开区域显示。
