# 《六域：边境交锋》数值设计 v0.5

日期：2026-10-08。状态：设计规范。38种单位数值沿用v0.4，新增明确的反击倍率、技能计算和修复边界，尚待完整对局验证。

## 基准与步长

- 步枪步兵：80 HP、0装甲、30固定基础伤害。30位于20–40范围内，攻击预览和实际结算一致，没有随机波动。
- 生命采用10点步长：轻型观察单位60–100，主力步兵100–160，主战装甲160–220，重型舰船最高300。
- 装甲采用固定减伤，0／10／20／30／40；不是百分比。重型舰船与坦克仍可被专业反装甲火力有效打击。
- 基础伤害20–100，目标类别与陆海空状态加成按10点步长配置。专门防空依靠对空加成，反坦克依靠对装甲加成。
- 碎石减伤10，工业废墟减伤20；最低伤害10，空中目标不享受地形减伤。
- 建筑方案的HP与装甲、修复40 HP、穿甲10、锚定装甲+20、狙击伤害+20等技能设计同步量级；反击结果允许5点步长，建筑不享受地形减伤。
- 移动、射程、视野、AP、能耗、成本和生产回合各有自己的单位，不乘十。

## 结算公式

标准伤害D=max(10,基础伤害+目标类别加成+目标状态加成+技能伤害项−目标有效装甲−目标有效地形减伤)。只选一种类别和一种状态加成。穿甲先减少装甲（最低0），锚定增加有效装甲，驻守/掩体增加有效地形减伤。震荡弹在普通标准伤害上减10再保底10。

主动攻击扣血=min(目标剩余HP,D)。普通反击扣血=min(攻击者剩余HP,floor(D×0.5))，专职防空反击扣血=min(攻击者剩余HP,floor(D×1.5))；先算减伤、再乘倍率、最后按HP截断。反击最小标准值分别5与15，不能再统一强行保底10。

当前HP不影响火力，未移动猎矛的伏击被动自动计入；普通伤害项取十位数，反击可能得到15/25/45/75等整数，不做十位舍入。

## 取舍与后续平衡

步兵保持廉价、免能源；轻型武器对坦克低效，需要反坦克支援。主战与重型单位增加生命和装甲，但承担更高成本、能耗或更低机动。侦察与工程单位以支援和机动为主。防空专长体现为对空输出，不能替代主战坦克与主炮舰。

占领现为所有单位的通用能力，不能再用“能占领／不能占领”作为兵种差异；步兵的优势来自价格、免能源与地面生存，陆战队的优势来自登陆。

本版数值为首轮对局初值。150%防空反击、维修限额和迷雾改变了实际战斗效率，不能直接沿用旧试验台结果证明平衡。

| 天幕主动攻击苍隼 | 30+40−10 | 60 |

| 云帆对苍隼反击 | (30+40−10)×1.5 | 90 |
| 海幕对苍隼反击 | (40+60−10)×1.5 | 135 |
| 穹海对苍隼反击 | (40+80−10)×1.5 | 165，实际扣血最多目标当前HP |
| 前哨在荒原反击前哨 | (30+10−0)×0.5 | 20 |
| 棱镜穿甲弹打磐石 | 60+10−max(0,30−10) | 50 |
| 长钉定点狙击打棱镜 | 60+40+20−20 | 100 |
| 弧光震荡弹打棱镜 | max(10,(60+10−20)−10) | 40，存活目标下回合移动预算−1 |

反击还需存活、合法距离、可反击权限与周期次数；高伤害例子不是必然触发的额外输出。完整交战例子见[技能与反击设计](技能与反击设计-v0.5.md)。

## 首轮平衡记录与调整顺序

每场记录地图、胜利模式、先手、迷雾、结束轮数、胜因、建筑归属变化、各型号生产/损失、主动与反击伤害、工程修复量、能源不足和部署堵塞次数。相同方案至少交换先后手比较，不以单场胜负直接改数值。

优先检查六种防空在150%反击下是否让飞机完全失去出场机会，以及便宜步兵、猎矛、工程车能否形成无解阵地。其次检查单位寿命、设施升级回本、Ⅲ级出场时机和全建筑残局长度。通常先调成本、射程、技能次数和地图位置，再改HP/基础伤害；任何调整另记版本，不静默改变已交付表格。

| 类别 | 关注目标 | 解释 |
|---|---|---|
| 普通步兵交战 | 平地约2次同型主动命中击毁；含反击时有先手与次数差异 | 80 HP与40实际同型伤害的锚点 |
| 主战装甲 | 专业反装甲约2—4次主动命中；轻武器明显低效 | 猎矛未移动60、长钉80，不计修复 |
| 专职防空 | 主动对空强、被飞机攻击后可造成显著反击代价 | 保留150%用户规则，通过成本等控制效率 |
| 工程修复 | 每目标每己方回合最多40，不能无限堆修 | 满血拒绝，死亡单位不能复活 |
| 低级型号 | 升级后仍有成本、免能源或机动价值 | 不要求Ⅲ级在每一项属性压倒Ⅰ级 |

以上为观察目标，不等于已经完成竞技平衡测试。
