# 六域：雾海回响——机装少女世界观提案

日期：2026-10-09。关联反馈：FB-20261009-002。状态：设定与美术评审稿，未替换 v0.9 运行内容。标题为候选名。
用户确定的方向：以游戏单位的美少女设计为核心，世界与主线允许重构；精美二次元立绘用于展示，Q 版美少女用于实际棋盘。旧剧情六位人物不作为改版的前提。

## 1. 一句话与玩家体验

雾海上的六个自治区依靠同一条能源航路生存。一次持续扩大的“晶潮”让中央决定切断边远地区的补给。玩家指挥由步兵、装甲、舰装和航空少女组成的协作联队，夺回能源节点、工厂与航道，在下一次风暴到来前，建立一条能让六域共同生存的供给线。

角色的吸引力来自她们各自的外形、武装、性格与协作方式：轻步兵守住一座灯火未灭的小城；坦克少女顶着火线开路；舰装少女送登陆队穿过雾海；侦察少女找到看不见的航线。战斗目标与这些特性直接相连。

## 2. 世界：六域为什么需要彼此

舞台是架空海洋世界“澄海”。人类主要生活在环绕内海的六片陆域，外海长期受风暴与浓雾影响，稳定跨域运输依赖沿岸航路。

海底矿物“潮晶”可以被加工成高密度储能材料，但提炼、充能与运输需要不同地区共同完成。“晶潮”是周期性的海底活动：它会扰动采集设施、损伤供电线路，并使远程通信充满干扰。它是有限的架空技术前提，不提供免费无限能源，也不能让少女随意施法。

| 地区 | 主要能力 | 无法独自解决的需要 | 美术气质 |
| --- | --- | --- | --- |
| 岚岸 | 粮食、轻工业、地方守备 | 缺少重型装备和能源提炼 | 青绿田野、白石小城、轻便制服 |
| 白沼 | 潮晶精炼、蓄能、医疗与维修 | 缺少稳定海运和高地防线 | 水网、发光管线、白灰工程服 |
| 盐湾 | 港口、船坞、跨域运输 | 依赖其他地区供应食品与零件 | 蓝白舰装、灯塔、橙色救援标记 |
| 镜原 | 航空、雷达、精密电子 | 依赖能源与钢材 | 银白机翼、深蓝机场、光学镜头 |
| 砺岭 | 装甲、炮装、重型制造 | 港口少，能源运输路线长 | 石灰岩、黑金属、菱形装甲 |
| 潮门 | 中央调度、主蓄能库、海峡通道 | 本身没有足够生产能力 | 高架枢纽、环形中控、庄重军装 |

六域合作并非一句友谊口号：缺少其中任一类供给，其他地区都会逐渐停摆。争夺据点因此决定谁能获得资源、谁能维持生产，而不是为了收集没有意义的旗帜。

## 3. 机装少女是谁

七十年前的大晶潮中，旧世联合研究院推出了“织星计划”：将具有自主意识的人工人格装入可维修的仿生躯体，让她们在危险海域、停电区和重污染设施中执行救援与维护任务。

第一代“星芯”采用成年女性外形的标准躯体。它是原型团队的设计选择，不是女性天然拥有特殊战斗能力。后续的躯体、维修设备、感知与武装接口围绕这套标准发展；六域重建后沿用成熟接口，形成今天的机装少女体系。本作中的三十八种军用机装都属于这个体系。

她们有触觉、情绪、记忆和独立判断，也会形成不同的兴趣与性格。她们在社会中拥有个人身份，既可以成为维修师、航海员和设计师，也可以选择加入联队。普通人类负责城市、工业、运输与治理，并没有从世界中消失。

“少女”是系列称呼；人物统一采用明确成年女性的外形与身份。Q 版是绘画比例，不意味着年龄降低。她们没有被统一设定成同一年龄、同一脸型或同一性格。

### 型号、个体与量产

“前哨”“棱镜”“浪锋”首先是机装型号呼号，表示装备与训练体系。一个型号可以由许多独立少女使用，个体以姓名或“棱镜-07”等联队呼号区分。单位立绘展示该型号的代表形象，同型号的多个地图单位并不表示把一个唯一人物复制多次。

现有生产可以解释为“预备队编成”：调入已完成训练的人员，装配库存机装，完成检查后部署。一个回合不会凭空制造成熟人格或建成整艘军舰。新机装少女的成长和制造发生在长期社会体系中，不属于战场即时生产。

不建立“只有剧情主角才能使用这辆坦克”的限制。三十八类单位就是三十八类可战斗角色形象，故事不依赖某个唯一英雄永远存活。

## 4. 她们如何真的战斗

星芯负责感知与判断，仿生躯体负责操作和近距离行动，“机装”负责提供装甲、武器、浮力与飞行能力。她们的可爱外形不会替代必要的机械结构。

| 单位 | 人物与机装关系 | 战斗逻辑与外形 |
| --- | --- | --- |
| 步兵少女 | 轻型躯体、枪械、携行电池与小队协作 | 轻装机动与守备；没有凭空抵挡主炮的能力 |
| 坦克少女 | 躯体与可展开装甲底盘连接，履带承担行进与后坐力 | 主炮由炮架固定；装甲与能源成本换取推进能力，战斗时底盘进入工作姿态 |
| 炮兵少女 | 携带或牵引炮架，支撑脚承受射击载荷 | 地面炮兵须先稳定炮位；远射程与近距盲区并存 |
| 舰装少女 | 连接具有真实排水浮力和推进器的舰装平台 | 在海上由平台承载；大型舰装不能开进陆地。陆战队的轻艇模块可以收拢上岸 |
| 航空少女 | 连接机翼、发动机和飞行框架 | 飞行靠推力与升力；不同翼形对应侦察、制空、载荷，需机场整备和补能 |
| 支援少女 | 维修机械臂、传感器、干扰设备等专门机装 | 修复是更换与恢复部件；扫描不是全知；干扰不是永久控制敌方人格 |

立绘可用机装收拢的展示姿态突出脸部、服装与美感；Q 版战斗形象采用机装展开姿态，把履带、炮架、浮力平台或机翼画清楚。大型舰炮与航空载具允许有辅助平台，不能为了人物比例把所需结构全部删掉。

## 5. 当前规则在新世界中如何成立

| 规则 | 世界观解释 | 对开发的意义 |
| --- | --- | --- |
| 一格一支单位 | 一格抽象一个战术区域；一个单位代表一名或数名少女及配套机装形成的战术编组 | Q 版显示代表角色；不把六边形大小当成身体尺寸 |
| 每单位 2 AP | 一个指挥窗口中有限的机动与战斗调度机会 | 回合不是一天，也不是统一秒数 |
| 金钱与能源 | 金钱支付零件、整备、运输与人员调动；能源是联队可调度的高功率燃料与蓄能预算 | 工厂、港口、能源站和收入仍有用 |
| 步兵／陆战队免能源 | 普通躯体与轻装使用已有携行储备和常规补给，不逐格扣战略能源 | “免能源”不等于没有能量来源；重机装仍逐格耗能 |
| HP 与装甲 | HP 是机装与编组的战斗可用程度，装甲是实际防护 | 受损会退场；不把每次掉血都写成身体创伤 |
| 单位被击毁 | 单位失去继续参战能力。可有应急脱离与后续救援，严重核心损坏仍可能造成不可逆损失 | 战场上损失单位、机装与资源；不增加免费复活技能 |
| 修复 | 在未完全退场的单位上恢复部件与战斗功能，受工具、距离和整备能力限制 | 保留工程车修复范围、次数与 HP 上限 |
| 全单位占领 | 每套机装都有近距接管终端；无守军时，地面接线、舰装接驳或航空投送接管探针可控制设施节点 | 航空也能按现有规则接管；不能绕过守军、距离与 AP 限制 |
| 迷雾 | 晶潮干扰与地形遮挡限制即时观测，依靠侦察与队间共享补足 | 外形漂亮的雷达也不能让玩家看见未观测敌军 |
| 24 编制、设施库存 | 联队的安全通信与整备保障有容量上限；设施只有有限待部署机位 | 不因新背景增加无限召唤 |
| 两方相同型号 | 六域采用共同的织星接口与装备标准，分歧是所属组织与命令 | 相同单位 ID 可复用；阵营徽记和色块明确区分敌我 |

这些是设定适配，不是本次已实现的新系统。现有特殊规则以运行数据为准，例如镇海允许移动后攻击；地面炮兵不允许。舰装外形不能自动附赠拦截，潜艇外形不能自动附赠隐身。

## 6. 冲突：每一方都为何而战

本轮晶潮提前到来，多个节点连锁失效。中央估算，以现有储备只能确保三片核心陆域的工业与人口供给。它颁布“静海令”：接管港口与工厂，收拢能源，并暂时停止边远地区的公共运输。

中央并非为了毁灭六域而行动。它相信局部牺牲可以保住总体，并担心分散指挥会导致抢运与能源网再次崩溃。但临时管制逐渐变成永久接管，救援船和维修队也被视为必须服从的军事资源。

地方联队也存在问题：部分自治区不愿分享储备，一些指挥队只保护本地。玩家的协作联队需要同时证明“不要永久军管”与“不能各自为政”，才可能得到其他地区支持。

| 阵营 | 目标与内部矛盾 | 游戏位置 |
| --- | --- | --- |
| 晨潮协作联队 | 保障六域的基本供给，重建共同调度；内部有人优先保护故乡 | 玩家可战斗阵营，沿用 union ID；青绿圆环 |
| 静海统筹军 | 保住核心工业与蓄能库，避免大范围停机；有人坚持封锁，也有人主张有限放行 | 对手可战斗阵营，沿用 red ID；珊瑚红三角 |
| 公共整备同盟 | 保住设施与民用通道，提供检修记录、技术与交接支持 | 中立社会组织，不新增第三套战斗阵营 |

双方都有机装少女，敌方角色同样可以漂亮、有个性、有责任感。阵营归属来自经历和选择，不能用“可爱的是我方、丑陋的是敌方”替代设计。

## 7. 主线故事：《把黎明送回六域》

开篇，岚岸的夜间电网连续熄灭。联队接到一份最后通行单：天亮后，中央将关闭盐湾航道，岚岸与白沼的补给会被停止。守备少女们原本只负责护送一列维修物资，途中发现沿路据点已经被统筹军接管。

她们可以撤回仍有储备的城市，也可以继续打开道路。协作联队选择后者。第一场胜利不是毁灭敌军，而是让维修车抵达供电站，让城市重新亮灯。

随后，工程少女发现，六域无法各自保住供电，但把地方备用网和中央主蓄能库分段连接，可以在低于原有峰值的功率下，维持所有地区的基本生活。这个方案需要重新夺回港口、空中观测、重型制造和海峡接线枢纽。它既不是一句“共享就好了”，也不是一个万能终端：每条线路都必须由实际行动恢复。

中央担心未经统一控制的重联会烧毁主库，拒绝开放枢纽。联队于是沿着六域推进，一边争取当地支援，一边用已经恢复的供电与运输证明方案可行。若她们为了速度破坏设施或放弃后方，自己也会失去继续作战所需的资源。

最后一次晶潮到来前，联队抵达潮门。航空少女标定安全线路，舰装少女保持海峡运输，炮装与坦克少女清除接线枢纽的火力封锁，步兵和工程少女完成设施交接。玩家的终局目标是接管中央枢纽，让分段供给上线。

主库得以保全，边远地区也获得有限但持续的能源。中央接受暂停静海令，各域签订共同最低供给、灾时协调与定期公开调度的协议。能源没有变得无限，下一场风暴仍会来；联队赢得的是继续合作和修复的条件。

尾声回到开篇的小城：灯亮起，少女们卸下机装，在港口等第一班恢复的渡船。她们的故事可以继续，但本季已经完整回答了为什么出发、为何占领、如何获胜。

## 8. 美术与叙事统一

- 完整立绘：精美二次元面部、发型、服装、机装材质与饰扣。三十八型号均有独立辨识点，不能只给同一女孩换发色。
- 游戏棋子：约 2.5—3 头身的 Q 版美少女，脸部可爱，装备更概括。保留同立绘的发色、服装主色与主武装。
- 三级体系：一级轻便、二级完整、三级厚重或大型化。重步兵不与轻步兵共用相同轮廓，三级不解释为人物年龄。
- 剧情画面：机装展开／收拢、城市灯光、港口复航与能源管线，承接战场行为。旧六位人物可退出核心呈现。
- 角色魅力：步兵的可靠、坦克的稳健、侦察的好奇、海军的爽朗、工程的细致，体现在武装与姿态。性格是设计倾向，同型号个体仍可不同。
- 展示双版本属于同一角色体系。Q 版不引入另一个世界或另一个年龄，也不改变射程、装甲或通行范围。
