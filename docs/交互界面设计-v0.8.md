# 六域：战场界面与直接操作 v0.8

交付日期：2026-10-09。适用剧情关卡、自由战役和规则测试场。

## 战场布局

地图占满浏览器内容窗口，以地图为主要操作区域。战场内隐藏大厅导航和页脚，摄像机根据实际窗口宽高设置视野，不产生页面纵向滚动。

| 位置 | 信息与操作 |
| --- | --- |
| 顶部 | 对局名称、金钱与每回合收入、能源与收入、编制、音效、暂停、菜单 |
| 左上 | 轮数、当前指挥官、胜利目标；部队、建设、记录和据点入口 |
| 左下 | 当前单位或建筑；单位生命、行动点、射程、技能与可展开详细信息 |
| 底部中央 | 悬停行动预览：真实路线、能源、预计伤害与合法反击；修复与干扰分别解释效果 |
| 右下 | 固定行动顺序、下一部队、结束回合、小地图和缩放工具 |
| 右侧 | 地图内抽屉：生产与库存、部队列表、建设规划、目标、行动记录、存档和菜单 |
| AI 回合右上 | 难度、观测／补给／战术／机动／交接阶段和经过视野裁剪的行动说明 |

菜单、生产、部署、建设和选择目标都位于战场框内。剧情使用字幕浮层，本地多人交接先显示遮挡页，确认接手后才显示下一方地图。图鉴和完整行动手册可从菜单进入独立页面，返回时恢复对局。

界面参考《文明 VI》的地图中心布局、边缘信息区及单位右键移动；参考依据为发行方的[官方操作手册](https://shared.steamstatic.com/store_item_assets/steam/apps/289070/manuals/CIV_VI_25TH_ONLINE_MANUAL_ENG.pdf?t=1740607040)。本作采用原创样式、图标和规则。

## 直接操作

1. 左键点击己方单位选中；再点击可达空格立即移动，点击合法敌军立即攻击，点击可接管据点立即占领。
2. 右键对当前选中单位下达同样的上下文命令。左键点击另一己方单位优先切换选择，右键保留原单位。
3. 移动不需要二次确认。攻击只有在同格存在多个合法目标时才弹出目标选择，避免误选驻军或建筑。
4. 选择主动技能后直接点击目标；无目标技能直接发动。应急修复只消耗 1 AP，预览显示实际可恢复 HP；干扰预览显示行动点影响。
5. 点击生产设施打开内部抽屉，选择型号并下单。库存条目进入部署模式，再点击原设施格或合法邻格立即部署。
6. 打开建设规划，选择建筑，再点击合法格立即开工。设施抽屉内左键点击建筑优先查看设施，并清除旧目标模式。
7. 非法目标给出规则原因，失败不扣资源。移动与攻击由同一规则引擎验证，隐藏阻挡按实际走过的格子结算。

地图悬停预览不执行指令。动画期间锁定新的行动，摄像机、暂停和音效操作仍可使用。规则先完整结算，再播放对应效果；自动存档保存完整结果，剧情和终局画面等最后一个效果完成后显示。

## 摄像机与键盘

| 输入 | 功能 |
| --- | --- |
| WASD／方向键 | 持续移动地图视角；短按也能移动 |
| 拖拽地图 | 平移视角，达到拖拽阈值后不再误触格子命令 |
| 滚轮、+、− | 缩放；滚轮朝指针所在地图位置缩放 |
| 点击小地图 | 定位视角 |
| 空格 | 暂停／恢复对局调度、当前动画和声音 |
| Tab、Enter | 聚焦格子、选择或提交上下文命令 |
| Esc | 关闭浮层或取消当前模式、目标和选择 |
| M、F、C、Q | 移动、攻击、占领、主动技能 |
| N | 下一支可行动的己方部队，仅本地人类行动阶段可用 |
| H | 定位观察方总部 |

输入框、下拉框、修饰键组合和剧情对话不会触发地图平移。窗口失焦、页面隐藏和换页清除按住的方向键，避免镜头持续漂移。暂停保留地图巡视功能，Space 长按不会反复切换状态。

## 观察权限与响应布局

地图只绘制当前视野内单位和已知建筑；建筑离开视野后显示最后观测记录。已选敌军离开视野后不再显示高亮，AI 自动行动不把隐藏坐标写入当前选中格。部队列表、N 和直接聚焦均受观察方权限限制。

AI 真正的指令计算一次，再通过 `GameAI.forViewer` 裁剪为公开决策区。隐藏动作只显示通用调度说明，私有威胁图、候选分数、坐标与资源不足原因不进入玩家界面。实际提交仍使用原始指令，公开说明为空不会阻止 AI 行动。

1100px、760px 和短窗口断点压缩信息区、小地图及单位面板；小尺寸抽屉限制高度并独立滚动。动作尊重系统减少动态效果设置。

## 实现入口

- `src/controls.js`：观察权限下的上下文指令解析。
- `src/battle-ui.js`、`battle.css`：地图、摄像机、HUD、内部抽屉与输入。
- `src/ui.js`：完整事务、自动保存、剧情、AI 调度与动作播放集成。
- `src/fx.js`、`fx.css`：动作、声音、暂停与清理。
