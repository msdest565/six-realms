# 《六域：边境交锋》验收用例 v0.5

日期：2026-10-08。以下是交付实现agent的验收规范，不是已执行的游戏测试报告。除特别说明，测试场关闭迷雾，双方单位满HP，目标在合法射程，地形为荒原，AP为2、反击额度1、技能可用、资源足够。每条使用独立场景，不承接上一条的损伤或次数。

P0为必须先通过的核心规则；P1为完整对局必需；P2为界面与资料一致性。规则来源为[规则总册](规则总册-v0.5.md)、[技能与反击设计](技能与反击设计-v0.5.md)、[经济与建筑设计](经济与建筑设计-v0.5.md)。

## 1. 胜利与占领（P0）

| ID | 场景与操作 | 预期结果 |
|---|---|---|
| WIN-01 | 开局分别选择总部模式与全部建筑模式 | 保存不同模式；对局中不能切换，读档保持选择 |
| WIN-02 | 总部模式，飞机从合法相邻空格占领无守军敌原始总部 | 花1 AP后AP归零，立即获胜，后续收入/操作停止 |
| WIN-03 | 总部模式，将敌总部HP打到0 | 总部保留为废墟，敌方归属不变，不立即获胜；后续占领才获胜 |
| WIN-04 | 全建筑模式，已占敌总部但仍有一个中立能源平台 | 不获胜，进度仍少1；不能忽略中立或海上建筑 |
| WIN-05 | 全建筑模式，最后一个非己方建筑为敌方废墟，占领它 | 保留其等级与0 HP，转归属后立即获胜 |
| WIN-06 | 初始登记25座建筑，合法新建一个城市地基 | 支付140，登记目标总数变26；完成与损毁均不减少或重复增加总数 |
| CAP-01 | 逐一用38型号，从合法本格或邻格占领中立建筑 | 均有占领权限；无需步兵专属标记；普通舰船从海洋邻格操作 |
| CAP-02 | 建筑格内有敌方飞机，己方地面单位相邻占领 | 失败且不扣AP；飞机占位也属于守军 |
| CAP-03 | 建筑内无敌军，但旁边有敌军 | 可占领；相邻敌军不自动阻止 |
| CAP-04 | 先移动再占领；另一个场景先攻击再占领 | 前者合法、AP归零；后者因攻击已结束行动而失败 |
| CAP-05 | 占领Ⅱ级受损城市，原所有者无订单 | 等级与HP保留，无即时收入；新所有者下一己方开始收入55 |
| CAP-06 | 占领有单位订单和两件来源库存的工厂 | 原订单与来源库存取消，无退款；原所有者释放3编制；完好工厂新所有者可重新生产 |

## 2. 占位、移动与部署（P0）

| MOV-05 | 三种炮兵移动后分别尝试普通攻击或震荡弹 | 全部拒绝；仍可占领；战列舰另场景移动后可炮击 |
| DEP-01 | 机场本格驻扎地面单位，尝试部署飞机到本格 | 失败；若合法空邻格存在，可部署那里；库存未丢失 |
| DEP-02 | 来源设施所有合法格都被单位占据 | 成品留库存、仍占编制，显示堵塞原因 |
| DEP-03 | 从军港部署普通舰船、陆战队、飞机 | 舰船只到海洋邻格；陆战队可合法陆地/海洋；飞机仍按来源设施与统一占位检查 |
| DEP-04 | 新部署工程车与步兵到两个不同合法格 | 均2 AP、本回合可行动；工程车修复额度1，不能多次部署刷新同一实例 |

| ATK-02 | 鸣雷100 HP在距离1攻击天幕100 HP | 主动50，天幕余50；天幕反击标准105、实际100，鸣雷阵亡 |
| ATK-03 | 天幕主动攻击苍隼130 HP | 主动60，苍隼余70；苍隼反击10，天幕余90；天幕自己的反击额度仍1 |
| ATK-04 | 六种专职防空分别对苍隼进行合法反击 | 标准反击伤害依次90/120/150/90/135/165，扣血按苍隼剩余HP截断 |
| ATK-05 | 轻坦直接攻击天幕，天幕存活且射程合法 | 天幕对轻坦反击30，确认150%也适用于合法地面目标 |
| ATK-06 | 同一防空单位在一个反击周期先后遭两次直接攻击 | 仅第一次合法且存活时反击；第二次额度0不反击；下次己方开始恢复1 |
| ATK-07 | 炮兵间接攻击防空单位；另场景对防空单位造成致死伤害 | 两种情况均不反击，附近防空也不代为拦截 |
| ATK-08 | 前哨被空袭后存活；驱逐舰/战斗机被空袭后合法反击 | 前哨无对空反击；后两者倍率0.5，不错误继承专职防空150% |
| ATK-09 | 同格有敌单位与建筑，分别选择两个目标攻击 | 每次只扣选中目标HP；攻击建筑不引发驻军反击 |
| ATK-10 | 直射地表目标隔山脊；另场景炮兵使用友军视野攻击 | 直射拒绝且不扣AP；间接合法，不消耗能源 |

## 4. 技能与回合（P1）

| ID | 场景与操作 | 预期结果 |
|---|---|---|
| SKL-01 | 工程车修复相邻70/100 HP友军，再尝试修另一友军 | 第一目标变100，实际恢复30；工程车AP0、额度0，第二次失败 |
| SKL-02 | 工程车尝试修满血单位或自己 | 都失败，AP和本回合额度不变 |
| SKL-03 | 两辆工程车依次修同一受损目标；下次目标所属方回合再修 | 同回合第二次失败；下回合可以再次修复40 |
| SKL-04 | 工程车在己方总部废墟同格使用修复 | 总部变40/240，功能恢复、仍原归属，收入下次结算才发 |
| SKL-05 | 工程车修相邻友军飞机；另场景修敌建筑或地基 | 飞机可恢复40；敌建筑和未完成地基非法 |
| SKL-06 | 棱镜对磐石使用穿甲弹；长钉未移动狙击棱镜 | 主动伤害分别50、100，按技能记冷却，允许合法反击 |
| SKL-07 | A第3回合扫描或掩体，查看B回合、A第4/5回合 | B回合效果保留；A第4开始到期且技能仍不可用；A第5可用 |
| SKL-08 | 弧光震荡棱镜后，在其下个己方开始刷新行动 | 本次伤害40；棱镜移动预算3→2，AP仍2；再下个开始预算恢复3 |
| SKL-09 | 干扰目标第N回合只有1 AP，多辆电子战尝试连续干扰 | 待生效/生效/抗干扰期再次选目标均失败；N+1为2 AP且受保护，N+2开始可再干扰 |
| TRN-01 | 第N己方回合提交1回合生产订单，然后对方行动 | 对方回合不推进；N+1己方开始完成，先收入再进库存 |
| TRN-02 | 城市Ⅰ升Ⅱ，在N+1完成 | N+1城市收入35，N+2收入55；升级不回复HP |
| TRN-03 | 第一次进入某方行动阶段 | 从600金钱/60能源结算为720/74；重复载入或重画界面不再发一次 |
| TRN-04 | 结束己方回合后，再检查该方冷却、队列和收入 | 不额外减少冷却、不推进队列、不追加收入；只切换行动方 |
