日期：2026-10-09。关联 FB-20261009-002。完成范围：风格设计与制作规范；正式全量美术、动画、音频及游戏接入另列交付阶段。
前置：[世界观与背景故事](机装少女世界观与背景故事-2026-10-09.md)、[38 型号与双版本美术](美少女单位与双版本美术规格-2026-10-09.md)。

## 1. 统一风格

风格句：**晨光、雾海、洁净工业、精致机装。**

完整立绘表现少女的美感与个性，Q 版表现兵种与行动，环境表现六域相互依存的供给体系。整体明亮、轻盈、有希望；机械、火炮和舰装保留重量，战术信息始终清楚。

| 维度 | 确定方向 | 具体执行 |
| --- | --- | --- |
| 世界情绪 | 危机中的协作与重新出发 | 开篇灯火熄灭，胜利后供电恢复、港口复航；日常画面温暖，交战画面清楚有力 |
| 人物 | 精美原创二次元机装少女 | 面部、发型、服装与主武装各有辨识点，38 型号都是角色设计对象 |
| 棋盘 | Q 版少女＋可读机械轮廓 | 2.5—3 头身；发型和主色沿用立绘；小拼缝、发丝和饰物简化 |
| 环境 | 雾海工业与海岸城邦 | 浅青水面、奶白建筑、蓝灰机械、克制的能源灯 |
| 界面 | 轻量联队指挥终端 | 浅底与深字，圆角面板配切角装饰；常用动作直接、按钮不伪装成装饰 |
| 动作 | 人物有表情，装备有力学 | 步兵迈步、履带平移、炮架后坐、舰装尾流、机翼与发动机工作 |
| 声音 | 海风、机械瞬态、温和晶体音 | 发射与命中可区分，确认音短，少量角色口令，不把每次点击变成长对白 |

## 2. 色彩、字体和材质

下表是游戏美术候选色，不直接改变运行 CSS。最终文字对比度应在实际面板、透明叠层与设备上测量。

| 用途 | 色值 | 规则 |
| --- | --- | --- |
| 雾白主表面 | `#F3F6F0` | 大厅、图鉴与面板底色；战场不铺成刺眼纯白 |
| 深海文字 | `#17364B` | 标题、主要文字、机械轮廓 |
| 海面蓝 | `#76B3C4` | 水域环境，饱和度低于人物与指令标记 |
| 晨潮青绿 | `#59CBB4` | 组织灯饰与圆环徽记；深色文字配套 |
| 静海珊瑚 | `#E58C84` | 对手组织饰条与三角徽记；不把整个地图染红 |
| 琥珀 | `#E6C77B` | 待确认、生产／整备与目标强调 |
| 干扰紫 | `#A58FC9` | 电子干扰、状态异常；与伤害颜色区分 |
| 深色遮罩 | `#0D2233` | 模态、暂停和人物背景；透明度按场景评审 |

组织色、玩家席位色和效果意义分开处理。现有 2—6 方席位仍用颜色＋编号，组织用圆环／三角。修复固定配“＋／维修图案”，反击明确文字标签，非法目标配禁用符号与原因。敌我不能只依赖红绿差异。

中文采用清楚的现代无衬线字，系统字体为默认回退；标题仅少量加宽字距，正文不使用装饰字体。角色名字与型号、资源数值与收入分层显示。主要操作和信息建议 14—16px 起，次要说明建议至少 12px；地图缩放后的微小文字转成屏幕尺寸标签或图标，不照搬世界坐标字号。

材质统一为三种主层：柔和布料、大块哑光装甲、局部光学／能源高光。复杂金属刻线只用于完整立绘与近景，棋子不重复它们。阴影方向统一从左上，人物脸与主武装应比地面纹理清楚；不同域不采用互相冲突的渲染方法。

## 3. 地形与地图风格

保持现有八类地形 ID 与通行信息，替换外观时核对道路邻接、海岸方向、山脊连通与迷雾权限。

| 地形 ID | 二次元外观 | 必须读到的规则信息 |
| --- | --- | --- |
| `plain` | 青灰低草、柔和块面、少量花与标桩 | 基础可通行；装饰不伪装成建筑或阻挡 |
| `road` | 浅色路面、清楚边缘和接缝 | 六方向正确连接；连续道路一眼可追踪 |
| `rubble` | 低矮碎石与断裂铺面，轮廓稀疏 | 比平地难走，不能混同不可通行山脊 |
| `ruins` | 奶白墙体与蓝灰残架，低饱和 | 与碎石不同的遮挡／防护；不遮住角色和范围 |
| `ridge` | 分面岩脊，深背光与清楚山线 | 不可通行与视线遮挡；相邻山脊连贯 |
| `water` | 透明浅水、河道与浅色石岸 | 与海洋区分；以当前运行规则判断通行 |
| `coast` | 浅沙色岸线，水面只朝真实海邻格展开 | 海陆边界与登陆位置 |
| `ocean` | 浅蓝至青蓝块面，低频波纹与少量反光 | 连续水域；波纹不是格线或射程标记 |

道路、水面、岸线与山脊延续现有上下文邻接渲染。六边形边界用薄中性色，选中格和指令范围再强化；不能靠满屏粗格线区分地形。

六域场景仍统一上述材质：岚岸加农田与白石、白沼加水网与配电管线、盐湾加码头与橙救援件、镜原加跑道与精密装置、砺岭加岩壁与重工、潮门加环形调度枢纽。新地标优先作为现有建筑的剧情副标题或装饰，不悄悄新增建筑类型。

迷雾用低饱和雾灰与弱纹理。当前可见、最后观测与未知三种状态需明确：旧建筑标记不显示实时状态；未知区域不播放角色、部署或工业活动以泄露情报。

## 4. 九类建筑

| 建筑 | 造型与动画关键词 | 玩家识别 |
| --- | --- | --- |
| 总部 `hq` | 环形指挥塔、天线、联队徽记；接管后线路亮起 | 最高指挥节点，与普通城市不同 |
| 城市 `city` | 奶白街区、蓝窗、屋顶花园；功能恢复后窗灯暖亮 | 收入与守备据点 |
| 市场 `market` | 青白棚顶、物流台、货箱；短整备灯提示 | 经济设施，不画成抽卡商店 |
| 能源站 `energyfield` | 潮晶蓄能柱、变压器与粗管线 | 地面能源来源 |
| 海上能源平台 `energyplatform` | 高架甲板、浮力座、采集臂、青绿指示灯 | 海上能源，周围有水；不画成可上岸船 |
| 兵营 `barracks` | 小型整备棚、训练标靶、轻装备架 | 轻装编成 |
| 工厂 `factory` | 起重臂、装配门、装甲支架与烟囱 | 重机装整备；订单与库存标记清楚 |
| 港口 `port` | 奶白船坞、吊臂、蓝白栈桥与系泊桩 | 海洋部署格和航道入口 |
| 机场 `airfield` | 跑道、机库、导航灯与控制塔 | 飞行机装整备；轮廓不与港口混淆 |

一至三级以增建侧翼、更多设备与灯带表示，保留稳定主形。地基独立叠层显示所有者与建造状态；角色站在建筑格时，不覆盖建筑类型与归属。

## 5. 镜头、尺寸与绘制层级

地图采用统一的斜俯视环境；人物采用略带俯视的三分之四 Q 版视角。单位六方向移动可以从少量朝向与合法翻转开始，但主炮、左右非对称设备与阵营文字不可无脑镜像。

坦克展示立绘允许履带收在腿侧；战斗工作姿态要连接展开桥架，让底盘承重与后坐成立。炮兵支架、舰装浮力平台与航空框架同理。人物不随主炮一起整体拉长，不靠脚下光圈假装飞行。

| 视距 | 表现 |
| --- | --- |
| 近景 | 完整 Q 版轮廓、清楚装备、HP／AP与状态 |
| 常用战术视距 | 简化 Q 版与兵种徽记；名称按选择展开 |
| 远景 | 席位＋兵种＋行动状态徽记，保留建筑类别与目标；隐藏微小人物细节 |

按实际屏幕尺寸确定这些切换，不只依据地图世界坐标。设计基准是人物展示区约 64—96px 可读，但更远镜头不能强行塞下所有文字。

从下到上的目标层级：地形→建筑地基与主体→路线／范围→角色机装→局部弹道与光效→HP／AP／席位／名称／目标标记→HUD与确认面板。效果不得盖住数据，所有纯装饰层 `pointer-events:none`。

目前 `GameFX.play` 在棋盘尾部加入动作层，可能位于标签层之上；接入新特效时要明确插入位置，不能只增大特效就认为风格升级完成。

## 6. 大厅、图鉴、生产与战场界面

| 界面 | 改版设计 |
| --- | --- |
| 大厅 | 雾海港口晨光背景，候选标题和联队标志；剧情、自由战役、规则测试场入口清楚，不加入与现功能不符的账号/抽卡/商城 |
| 图鉴 | 立绘成为主体，旁边固定型号、兵种、等级、优势、弱点与技能；点击切换同角色 Q 版和机装说明 |
| 生产设施 | 单位头像＋型号＋成本／能源／回合，立绘预览按需展开；固定部署格、三支 FIFO、阻挡原因常见且清楚 |
| 桌面战场 | 地图主导，边缘信息区采用浅色终端面板；选中卡给 Q 版／头像、HP／AP、四类主要指令 |
| 手机战场 | 可收起底部单位面板；结束回合独立固定；地图双指缩放，小地图、日志与大立绘按需打开 |
| 剧情／简报 | 地区小景与型号频道头像、短电台字幕；无需占满屏幕的 NPC 立绘队列 |
| 终局 | 供给线重新亮起、港口复航的视觉回报；统计可读，失败给退场／整备氛围与重试入口 |

常用操作不依赖悬停，触屏点目标先看代价再确认。大立绘放入详情页，不挡住待选格；角色语音和展示动画也不阻塞指令判断。新世界名是候选标题，正式更名需要同时更新大厅、HTML标题、存档展示与营销文案。

## 7. 动作与特效风格

标准节奏为“读得出动作意图→释放武装→命中反馈→快速回到战术”。人物表情、发梢、裙摆和机械部件可增加魅力，但常规攻击不反复插入全屏立绘。

- 移动：轻步兵短迈步，坦克履带推进，海军平台轻浮动，航空推进与悬浮；动作由实际路径决定。
- 攻击：轻武器短枪口光，主炮短后坐，炮兵先稳支架，导弹可读点火与尾迹；命中使用短碎屑／局部冲击。
- 技能：修复用工具与恢复线，扫描用雷达扇扫，干扰用紫色断链；护甲提升用机械锁定，不画成免伤法术。
- 受击与退场：短状态反应与机装失效，保留可读角色；不采用漫长的满屏烟雾。
- 占领：接管探针、短联队徽记确认、建筑线路换色；无条件不播放成功效果。
- 部署：出整备位、展开机装、短敬礼／确认姿态；不是从抽卡光柱中召唤唯一角色。
- 镜头：默认不震屏、不全屏白闪；局部特效为主。减少动态去位移夸张、摇晃与持续粒子，保留静态结果。

明确时轴、38 型号动作族、八技能与复合事务见[动作设计](二次元动作设计-2026-10-09.md)。发射、命中、接管与部署的语义标记同声音设计一致。

## 8. 音乐、音效与角色口令

音乐以清透钢琴、轻弦乐、合成器铺底和适度电子节奏组成“雾海与协作”的声音主题。战斗加入节奏与机械打击，压力来自配器和节拍，不靠持续大音量。

步枪、履带、舰装、航空、工具与电子设备具有不同声纹；少女短口令给身份感，连续移动、AI大队列与重复选中受到限频。重要结算依靠画面与短确认音，同时有静音模式。

[音效与音乐设计](二次元音效与音乐设计-2026-10-09.md)包含命名、事件映射、章节主题、音量组、资源预算、浏览器与手机限制。现有合成声可作声音原型，但不记作已经录制的角色配音或完成的原创配乐。

## 9. 开发交付与验收

首批闭环选择前哨、棱镜、浪锋：批准立绘与 Q 版工作姿态→整备单角色图层与锚点→移动／攻击／受击／占领／部署→同步声音→一个地图小场景与一个手机选中面板。后续按全部三十八型号扩展。

| 工作包 | 必交产物 | 完成判据 |
| --- | --- | --- |
| 环境与 UI | 色彩／字号／图标规范，8地形、9建筑与三级扩建，桌面与手机页面 | 场景同风格，功能类型与按钮可读 |
| 单位 | 38主立绘、38套Q版基础形象、头像、必要海陆状态 | 型号不漏、双版本对应、工作姿态成立 |
| 动作 | 通用状态、动作族、八技能、三档时轴与事件标记 | 反击、占领、FIFO顺序正确；不修改规则结算 |
| 声音 | 合成预听／声音草案、正式SFX清单、BGM谱例/配器规范、可选台词 | 时点对齐、限频、静音、暂停、迷雾边界正确 |
| 接入 | 资源登记、内容源修改、渲染与音频模块集成 | 旧存档正常、离线可用、资源路径正确 |
| 验收 | 视觉／声音／手机设备记录、性能对照、已知边界 | 区分设计已完成、资源已制作、运行已接入 |

拥挤阵型、单位与建筑同格、长炮／机翼跨格、六方颜色、迷雾、减少动态和后台恢复必须实际检查。建议使用360／390／430px竖屏、低高度横屏和24单位场景建立基线；没有设备数据前不宣称已达流畅度目标。

工程入口：`src/art.js`、`game.css`、`battle.css`、`src/battle-ui.js`、`src/fx.js`、`fx.css`、`src/ui.js`与内容构建来源。动作与声音只消费经过观察权限裁剪的成功事件，暂停／跳过／换页／读档不重新执行游戏命令。
