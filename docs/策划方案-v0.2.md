# 《六域：边境交锋》策划方案 v0.2

日期：2026-10-08。阶段：策划、单位、美术与交互规则试验。当前以本版为准；无版本后缀的 v0.1 文档保留为历史草案。金钱与能源取代单一能源；轰炸机按最新规则允许攻击陆地与海洋，禁止攻击空中。

## 游戏定位

在架空工业星球的沿岸战区，指挥步兵、装甲、舰队与机群，争夺城市、能源点和生产设施，用六边形地形与三军配合摧毁敌方指挥总部。

桌面浏览器优先，HTML + CSS + 原生 JavaScript + SVG，无外部依赖。保留轻量回合战棋的鼠标操作和结果预览，增加深度来自地形、经济投资、能源路线和军种协同。完整标准局目标 35–50 分钟、约 18–24 个轮次，时长待完整对局验证。当前页面是设计工作台，已能体验部分规则，还不是完整对战游戏。

## 设计支柱

1. 六个方向创造位置选择：海岸通道、城市掩护与道路共同塑造战线。
2. 行动先看结果：显示路径、实际能耗、个别射程、目标状态、伤害组成与不能执行的原因。
3. 经济和机动形成取舍：金钱决定扩军或投资，能源决定把哪些部队送往前线。
4. 三军互相支援：步兵占领，装甲突破，舰队沿岸支援，空军跨越地形，防空限制飞机行动。
5. 复杂度保持可控：双资源、三级设施、确定伤害、同构阵营；暂不增加弹药、维护费、英雄、个体单位能源槽、独立科技树、朝向装甲或潜航层。

## 世界与参考

赫利俄斯–6 的沿岸工业城市在殖民政府撤离后分裂。远征联合以救援和勘测设备改造军用平台，赤岩防卫依托采掘工业和旧防卫网络，双方争夺城市运作所需的税收、能源与港口。

联合军采用浅灰装甲、青绿识别灯、圆环徽记；防卫军采用灰褐装甲、珊瑚红识别板、三角徽记。首版双方规则和数值相同，先通过配色与徽记建立身份。

参考军事战略地图的轮廓清晰度和设施识别方向，参考入口为 [EasyTech《世界征服者4》官方页面](https://easytech.itch.io/world-conqueror-4)。本项目采用原创架空近未来设定、单位、建筑和界面；资源与等级数值为本项目设计。

## 核心循环与回合

观察战场 → 预算与设施决策 → 选择部队 → 预览路径或目标 → 移动 / 攻击 / 占领 → 结束己方回合 → 敌方行动 → 收入和生产完成 → 下一轮。

“己方回合”是一方的行动时段，“轮次”是双方各完成一个回合。每方自由决定部队激活顺序，完整游戏双方分别拥有国库、能源储备和生产队列。

己方回合开始：按既有建筑等级结算收入 → 完成建设、升级与生产订单 → 刷新 2 AP、反击额度和技能冷却 → 部署与行动。刚完成建设或升级的收益从再下一次结算生效。当前“推进试验回合”只结算联合军经济并刷新行动，没有敌方决策。

- 每单位每回合 2 AP；一次移动花 1 AP，路径受移动预算、地形、同层占位和能源限制。
- 可以移动后攻击或连续移动两次。攻击花 1 AP 后结束单位行动，不能再移动或攻击。
- 自行榴弹炮本回合移动后不能攻击；战列舰暂不采用同样限制，以低机动和高耗能源约束。
- 完整版占领、修复和主动技能花 1 AP 后结束行动，与普通攻击互斥。
- 等待结束单位行动；正式版结束回合前提示未行动单位，技能初期可关闭。
- 当前“重置行动点”只用于体验，不发收入或恢复能源；“恢复场景”重置整个试验。

## 六边形地图、占位与移动

尖顶六边形使用轴坐标 `(q,r)`，第三坐标 `s=-q-r`。距离为 `max(|dq|,|dr|,|dq+dr|)`，邻居为 `(1,0),(1,-1),(0,-1),(-1,0),(-1,1),(0,1)`。

工作台为 13×9、117 格沿岸展示地图，用于集中验证三军和经济，不宣称已完成地图平衡。完整标准地图拟用 19×13，教程 9×7；需校准双方到中立城市、能源点、港口的距离和部署空间。

每格最多一个地表单位和一个空中单位。陆地与海洋共享地表层，两栖部队与舰船不能挤在同一海洋格；飞机可与下方部队或建筑共格。同层存活单位占据的格子不能穿过或停留，首版不加入控制区。建筑可与一名地表驻军共格。

| 地形 | 地表进入预算 | 减伤 | 中间格遮挡 | 规则 |
|---|---:|---:|---|---|
| 荒原 | 1 | 0 | 否 | 普通陆地 |
| 道路 | 1 | 0 | 否 | 一次移动全程进入道路，预算 +1 |
| 碎石 | 2 | 1 | 否 | 用机动效率换保护 |
| 工业废墟 | 2 | 2 | 是 | 可驻守的陆地掩护 |
| 河滩 | 2 | 0 | 否 | 陆地浅水；游隼进入预算 1，普通舰船禁止 |
| 海洋 | 1 | 0 | 否 | 普通陆军禁止，舰船与两栖部队允许 |
| 海岸 | 2 | 0 | 否 | 陆地格，允许两栖登陆，普通舰船禁止 |
| 山脊 | 禁止 | 0 | 是 | 阻挡地表通行 |

空军进入所有地形均花 1 移动预算，不获得道路奖励，不受下方单位阻挡，不享受地形减伤。能耗按进入格独立累计，详见经济设计。

## 当前状态与攻击范围

军种是生产组织分类，当前状态是攻击目标分类。空中层始终为空中；地表层在海洋为海洋，在其他合法地块为陆地。海军陆战步兵和两栖轻坦上岸后变为陆地状态，军种仍为海军。

| 攻击者 | 陆地 | 海洋 | 空中 |
|---|---|---|---|
| 普通单位：步兵、坦克、炮车、普通舰船等 | 允许 | 允许 | 禁止 |
| 直升机、轰炸机 | 允许 | 允许 | 禁止 |
| 明确防空：天幕、潮刃、巡岚、苍隼 | 允许 | 允许 | 允许 |

每单位有独立的最小与最大射程：步枪步兵 1、主战坦克 1–3、榴弹炮与战列舰 2–4、直升机与战斗机 1–2、轰炸机 1–3。具体数值见 [单位设计](单位设计-v0.2.md)。三类飞机的移动预算 4 / 7 / 9 表示机动航程，与武器射程分开。

攻击权限通过后还要满足距离、AP、敌我、存活和视线。普通单位可攻击海洋目标不代表可以进入海洋；沿岸坦克可以攻击射程内舰船。没有防空能力的单位遭空袭时也不能对空反击。

### 视线与战争迷雾

地表直射地表目标时，山脊和废墟阻挡中间射线，起点和目标格不遮挡自己；沿格边界的射线任意一条相邻线通畅即可。间接火力越过遮挡。攻击空中目标或由空军攻击不受地表射线遮挡，仍检查状态与距离。

完整版敌军必须被任意友军当前看见，不允许盲射或攻击迷雾里的旧位置；空军观察可越过地表遮挡，地表单位视野使用地表视线。探索过的地形保留，动态信息只显示当前可见内容，AI 使用相同信息。试验台全图可见，尚无迷雾。

## 战斗与反击

确定性伤害：`max(1, 基伤 + 对轻型或装甲加成 + 对当前状态额外加成 − 装甲 − 地形减伤)`。当前生命不影响火力，HP 为零移除；一次攻击一个目标，首版不加入溅射。建筑为装甲类别，并按位置区分陆地或海洋状态。

长钉攻击荒原棱镜：`5+3−2=6`；棱镜攻击废墟长钉：`5+1−2−2=2`。苍隼对陆地、海洋额外 −2，对空额外 +3；轰炸机可攻击坦克和舰船，不能攻击飞机。

正式反击：直射目标存活且可反击时，检查攻击者状态、射程与视线，造成普通伤害一半，向下取整、至少 1。从自己回合开始到下次自己回合开始最多一次，不花 AP、不引发再次反击。间接炮击不触发反击；炮车、工程车、战列舰、轰炸机和建筑不反击。反击复用攻击权限，普通单位不能对空反击。

正式预览显示伤害、反击和双方剩余 HP。试验台仅执行普通攻击，明确标注未结算反击；技能与被动尚未实现。

## 经济、建筑与胜负

金钱用于建设、升级和生产；能源用于移动；步兵免能源。9 类建筑分经济、资源、生产；四种生产设施三级，高等级保留低阶兵种。数值、订单和部署规则见 [经济与建筑设计](经济与建筑设计-v0.2.md)。

占领依靠前哨、哨兵、猎矛、浪锋四种步兵。建筑可以摧毁，停止收益和生产；总部不可占领，摧毁敌方总部获胜。取消旧版能源节点和信号分胜利，首版保留总部目标与主动认输。消灭所有部队不会自动获胜，只要总部和生产尚在仍可继续。首版不设轮次计分上限。

## 地图与教程

1. 陆战训练：步兵免能源、坦克扣能源、地形与行动顺序，占领和工厂生产。
2. 工业争夺：城市收入、能源站供给、设施升级，投入经济或补兵的时机。
3. 海岸行动：舰船海洋移动、陆战队登陆、两栖轻坦支援，海上能源平台收益与护航成本。
4. 空域争夺：双层选择、普通单位不能对空、防空护航轰炸机对地对海攻击。

标准地图提供陆地主通道、海岸交界、外侧海路三条路线。双方初始附近保留基础生产和供能源，中部经济点形成争夺动机；高级重装不应在开局封死所有通道。

## 美术、界面与技术

资源栏显示金钱、能源和每回合增量；选中面板显示当前状态、移动、射程与能耗。地表 / 海上和空中独立选择，共格显示另一层小标记。攻击失败解释无法对空、射程、遮挡或移动后不能炮击。设施页显示等级、可产兵种、时间、队列、升级费与库存拥堵原因。
