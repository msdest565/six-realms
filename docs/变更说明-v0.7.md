# 《六域：边境交锋》变更说明 v0.7

日期：2026-10-08。本轮交付仅为设计文档、设计JSON与SVG审核图，运行代码仍待实现agent接入。

## 新增自由战役

独立模式《六域演习》开放建设、升级、全部38种单位和完整陆海空机制。小/中/大为271/547/919格，小型2方、中型2—4方、大型2—6方；固定地图共有9套人数变体，另提供三个地貌方向的可复现随机地图生成规范及固定失败回退。

所有地图包含八地形、九建筑、每方完整四生产设施、初始总部守军、陆海能源设施与空能源点。详细出生坐标、初始资产、地形分布、扩张移动点、港口空间、可达性与地图哈希同步提供。最多六方的胜负、出局资产、队伍、回合周期、反击、共享视野和保存规则补齐。

## 统一能源设定

第二资源统一为能源；资源地块为陆地/海洋能源点，建筑为陆地能源站/海上能源平台，移动成本为能耗。相关单位、经济、剧情、地图、验收、历史文档显示术语和设计配置同步改名；已有数量、价格、收入、HP、装甲、伤害和移动消耗等量迁移。

旧代码字段只在[能源迁移说明](能源系统设计-v0.7.md)中列为转换输入；当前文档数据使用energy、energyfield、energyplatform。剧情JSON标记design-campaign-0.6-energy-0.7，原七关安排、证据链和剧情时间预算不改变。历史版本仅回填术语，历史玩法与数值不因此成为当前规范。

## 规则适用范围

v0.5继续负责单位数值和基础动作，v0.6继续负责七关剧情与≤3小时主线，v0.7负责能源统一、自由战役和多方规则。剧情与自由战役分别保存进度。自由战役为额外可重玩对局，其大型全建筑目标时长允许超过三小时，可保存续玩。

总部胜利在自由战役多方局表现为夺原始HQ淘汰该席、最后存活队伍获胜；全建筑模式总部只转移归属，全部登记建筑归同队才赢。投降和不可恢复僵局分别按多人规范处理。全部单位仍能占全部建筑，专职防空主动攻击/150%反击、工程车每己方回合一次技能与统一单格占位继续生效。
