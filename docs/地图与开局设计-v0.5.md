# 《六域：边境交锋》地图与开局设计 v0.5

日期：2026-10-08。状态：标准局设计基线，尚未经实战平衡验证。当前13×9工作台展示地图不作为正式开局；本文件给出可以复建和验收的19×13标准地图。

## 1. 地图规格与坐标

地图名“沿岸争夺”，19个轴坐标列×13行，共247个六边格，采用轴坐标平行四边形边界。表格使用零起始坐标（列c，行r），c=0—18、r=0—12；列c就是轴坐标q，行r就是轴坐标r。绘制时每行相对上一行右移半格。

本标准地图不是旧测试场的奇数行偏移矩形，不能再套用q=c−floor(r/2)转换。统一使用q=c，才能保证以下180度镜像在六边邻接、距离与通路上严格对称。

轴坐标邻格为(q+1,r)、(q−1,r)、(q,r+1)、(q,r−1)、(q+1,r−1)、(q−1,r+1)。距离为(|Δq|+|Δr|+|Δq+Δr|)/2。180度镜像为(c,r)→(18−c,12−r)，双方使用镜像开局。

## 2. 完整地形生成顺序

下表从上到下覆盖地形；最后生效的条目优先。建筑不能在生成时偷偷把不合法地形改为荒原。

| 顺序 | 格子条件 | 地形 |
|---:|---|---|
| 1 | 全部247格 | 荒原 |
| 2 | r≤2或r≥10；以及c=0或c=18 | 海洋 |
| 3 | r=3或r=9且1≤c≤17；以及c=1或c=17且3≤r≤9 | 海岸 |
| 4 | c=9且4≤r≤8 | 浅河 |
| 5 | r=6且2≤c≤16 | 道路；其中(9,6)为桥梁道路，按道路规则通行 |
| 6 | (6,5)、(12,7)、(6,7)、(12,5) | 山脊 |
| 7 | (8,5)、(10,7) | 工业废墟地形 |
| 8 | (8,7)、(10,5) | 碎石 |

上、下海域通过两侧海洋列连通；中心道路连通陆地双方总部，浅河在中心桥梁处可通过。没有永久不可到达的建筑目标。普通舰船停在海洋，可相邻占领海岸建筑；能源平台只能在海洋能源点上。

联合军与防卫军分别先手各测试一次；默认随机先手。不得用同一组展示单位及其未核算预算替代此正式开局。

## 6. 对局目标与平衡观察

总部模式目标18—24轮、35—50分钟；全部建筑模式目标24—36轮、45—70分钟。以上为设计目标，不能作为已经验证的结果，也不会在目标轮数到达时强制判胜。

| 观察项 | 首轮验证目标 | 发现偏差时优先调整 |
|---|---|---|
| 先后手公平 | 镜像换先手后没有稳定的首两轮总部必胜路线 | 开局位置与道路，不优先增加大量新规则 |
| 经济增长 | 前线城市、能源站均有争夺价值 | 位置、收益、初始资源 |
| Ⅰ级单位价值 | 不升级也能在前几轮完成占领、防空、侦察职责 | Ⅰ级成本与部署空间 |
| Ⅲ级出场 | 需要连续升级和2回合生产，不在第一轮免费出现 | 设施升级费与初始建筑等级 |
| 飞机占领 | 有快速夺点机会，同时会被单格阻挡和专职防空反击威胁 | 机场位置、航空成本与能耗；保留全单位占领能力 |
| 全建筑残局 | 海上和侧翼目标可到达，废墟不会因无法重建而卡胜利 | 连通性、建筑位置与胜利提示 |
| 港口堵塞 | 两方都有多个合法海洋部署邻格 | 港口地形与初始舰船位置 |

本版正式局不开启经验升级、运输舰装载、不同阵营科技树或独立潜航。这些机制如未来加入，应另立版本并修改胜负与存档契约。

## 7. 教程与测试场

教程按“移动和占位 → 普通攻击/反击 → 任意单位占领 → 生产与能耗 → 防空150%反击 → 工程修复 → 迷雾侦察 → 两种胜利模式”展示；使用固定简短场景，不必同时展示38种单位。

既有13×9工作台可作为全图可见的单位测试场，界面必须标明“测试场”。允许直接放置单位、调整资源，不把测试场胜率和免费高级部队用于标准局平衡结论。标准地图文件与测试场文件分别维护。
