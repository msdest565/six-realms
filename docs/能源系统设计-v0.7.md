# 《六域：边境交锋》能源系统设计 v0.7

日期：2026-10-08。状态：全模式统一术语与数据字段规范。用户确认将此前资源及其产地统一改为**能源**；本次数值等量迁移，不进行第二次数值平衡。剧情、自由战役、单位、经济、地图、验收及文档地图附件均采用本文件命名。

## 1. 统一概念

游戏使用两种资源：**金钱**与**能源**。金钱支付建设、升级和生产；能源支付单位实际移动。能源是抽象的军用动力与补给额度，覆盖不同装备需要的动力来源，不模拟真实电网、电池充放电、发电功率或单位独立能源仓。

每方独立拥有共享能源库存，队友不自动合并或转赠库存。步兵与陆战队的移动能耗仍为0；车辆、舰船、飞机按原单位档案的每进入格消耗执行。两栖轻坦进入海洋2能源/格，进入其他合法地形1能源/格。装甲、HP、伤害、移动力、射程和生产价格不因改名改变。

资源不足时不能提交超出已知可支付预算的移动，但攻击、反击、占领、工程修复和单位生产继续按各自条件执行。高移动点数的地形不会把每格能耗再次乘倍数。没有停驻维护费、能源自动流失、强制返航或自动缴械。

## 3. 单位、剧情与美术

单位面板统一显示“能源/格”；移动预览显示“预计消耗X能源”，库存显示“能源Y/300”。专职防空150%反击仍不扣能源。工程车每己方回合一次技能、修复40 HP，仍不支付能源费用。

剧情中的供给争议统一为能源运输、能源配额与能源设施调度。C03档案证据仍表示关键物资在袭击报告之前就被转移，人物关系、七关任务与对白触发顺序不变。全部剧情关卡初始资源只是将资源名称和字段改名，数值继续按关卡配置执行。

资源图标使用闪电，陆地能源站使用储配站/电力设施轮廓，海上能源平台使用海上设施与闪电标识。小地图与图例采用“能”“平台”，数值表与详细面板显示全称。旧工作台资产的迁移由实现agent执行；文档SVG已同步采用新术语。

## 4. 新数据契约

| 使用位置 | 新字段/标识 | 规则 |
|---|---|---|
| 玩家库存与收入 | resources.energy、income.energy | 整数，库存0—300 |
| 开局资源 | initialEnergy或initialResources[玩家ID].energy | 与所在配置结构一致，不同时存两份不同值 |
| 单位基本移动成本 | energyPerStep | 每实际进入格扣除；0合法 |
| 两栖轻坦海洋成本 | seaEnergyPerStep=2 | 陆地基本成本为1 |
| 陆地建筑类型/资源点建筑 | energyfield | 玩家名称陆地能源站 |
| 海洋建筑类型/资源点建筑 | energyplatform | 玩家名称海上能源平台 |
| 能源点集合 | deposits.land、deposits.sea | 名称为陆地/海洋能源点；坐标集合结构沿用 |
| UI与日志 | energy | 统一使用能源文本与闪电图标 |

文档数据已采用上述资源与建筑标识；单位完整能耗值继续以[单位设计v0.5](单位设计-v0.5.md)为唯一数值来源。不能只改菜单文本而保留两个可独立扣款的资源池，也不能把海上能源平台改成陆地建筑状态。

旧代码/旧存档迁移对照仅供实现，不是玩家术语：资源字段`oil`→`energy`，单位字段`oil`→`energyPerStep`，建筑类型`oilfield`→`energyfield`，`oilrig`→`energyplatform`；包含旧字段的初始值、收入数组、技能说明、AI估算、移动预览、存档、日志、资产映射和导出脚本须同步迁移。原建筑实例ID作为存档身份可保持不变，迁移类型字段与显示名称即可。

文档版剧情JSON的schemaVersion更新为design-campaign-0.6-energy-0.7，并记录resourceTerminologyVersion。旧存档加载时进行一次性映射；若新旧字段同时存在且值不同，明确报错，不猜测、求和或重复发放。新存档只写新字段。
