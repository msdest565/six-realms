## 实际战斗与操作

- Lv1主动、Lv3实时光环、Lv5每关一次大招，Lv6—10参数强化。数值统一进入属性、射程、机动、视野、能耗、伤害/反击及AI判断。
- 技能耗尽剩余AP；CD与临时效果按施放者己方回合计算。大招充能来自后续己方回合、主动与每回合一次普攻，反击不充能。
- 结构25%分伤 → 共享护盾池 → 单位HP；多目标攻击先固定全部命中，再逐一结算合法反击。普通单位也能获得盾和光环，炮兵移动禁射及防空150%反击保持。
- 单目标技能：图标 → 合法地图格/单位，直接施放。多目标技能：屏幕边缘预览，可指定治疗/护盾对象、减少附加命中，主攻击目标保留；确认后一次提交。基础移动/攻击/占领仍直接点图。
- 专属技能图标、15种SVG演出和15个独立程序音效事件。显示真实盾损、回血、结构伤害与反击；普通攻击仅损盾时也显示。支持静音、快速、低动态、暂停及取消清理；落点最多8、每技能提示最多4个合成声源，光环进入提示每角色至少间隔0.8秒，退出无声。
- 唐砺主动可合法直射空置敌方结构；同格守军仍由设施分伤。群攻主目标仍限合法单位，资源据点无HP，不可被攻击。
