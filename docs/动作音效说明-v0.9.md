# 六域：复合动作与空间声音 v0.9

本次延续 v0.8 的原创本地 SVG 动作与 Web Audio 合成音效，补充自动占领、自动出库的完整动作顺序，以及轻量双声道环境声。没有外部音频文件、下载、网络请求或第三方引擎。效果模块不改变任何核心规则状态。

## 复合事务

`GameFX.capture(state, command, viewerId)` 记录操作前可见实体和事务边界。`GameFX.plan(before, after, command, viewerId)` 除当前主指令外，按核心实际新增事件的顺序添加效果：

- **移动 → 占领 → 出库**：先沿实际走过的路径移动；核心确实额外消耗行动点并占领时再升旗；如果源设施的固定部署格被释放，再显示该设施 FIFO 队首的自动部署。只有移动进入格而没有成功占领时不会显示升旗。
- **回合开始的批量生产与出库**：每个实际部署实例播放一次短渐入和波纹，按核心事件顺序排列；回合提示按真实回合事件位置播放。阻塞部署格时保留的库存不产生部署动画。
- **攻击后释放部署格**：攻击和合法反击完成后，再显示核心实际自动部署的单位。效果模块不推测不存在的增援。
- 手动部署与自动事件相同实例不会重复播放。事件识别支持 `automatic: true`，部署事件读取 `unitId`；老存档没有完整事件字段时，仅对本次新生成且当前可见的实例做保守补充。

动画开始时先隐藏待部署实例与标签，防止它们提前显示在地图上；轮到该实例时短暂渐入，完成即恢复正常画面。移动途中保留目标建筑的旧归属地块，升旗阶段才恢复新归属。单位标签 `data-unit-label="实例ID"` 和建筑标签 `data-building-label="实例ID"` 与对应原画同步隐藏和恢复，不受标签层位置影响。

所有已知路径、伤害、反击、技能和毁坏效果继续使用 v0.8 的观察限制。完全隐藏的敌方出库不会显示单位、坐标、型号或部署声音。视野被迷雾隔开的移动仍分段显示，不绘制连接隐藏路段的完整路径。

## 声场与环境

新增 `GameFX.setAmbienceEnabled(bool)` 独立控制背景环境音。它也受现有音效总开关、总音量与空格暂停控制。`GameFX.setScene({ terrain, active })` 接受当前观察者合法看到的地形字符串、地形数组或地形数量对象，仅使用已知地形与建筑类别：

| 可见场景 | 轻环境声 |
| --- | --- |
| 海洋、海岸、军港、海上能源平台 | 起伏的双声道海浪、海风与很轻的低鸣 |
| 道路、城市或工业设施周边 | 风声与轻机械低鸣 |
| 平地、山脊、林地等陆地 | 较轻的风声 |

不会从部队数量、型号、隐藏敌军、资源存量或未知坐标决定声音。未知字段会被忽略；同一场景的重复镜头更新不创建新音频节点。UI 以当前视野内镜头附近的地形作为输入；必要时可使用观察者自己的总部周边已知地形。

环境声为缓存的八秒双声道合成缓冲、低鸣与慢幅度变化，一次最多七个环境音频节点。换场时立即停止并断连旧节点；暂停、静音、音量为零、环境音关闭、`active: false` 或 `cancel()` 都会停止环境声。恢复时沿用缓存缓冲创建一组新的节点，长期运行不会积累已经结束的节点。背景层较轻，并有短渐起，不添加动作等待时长。

攻击声音增加短促高频冲击、炮口主体和较轻机械尾声；已观测动作的左右声像由当前地图镜头内的位置决定，最大左右偏移为 0.65。看不到来源的攻击只在已观测命中位置发声。移动补充较轻的尘土、脚印和尾迹渐消，避免大量粒子遮住单位。

## 集成

```js
// 人类点击或键盘手势内调用；AI 不自行创建音频上下文。
GameFX.unlock();

// 进入战场或镜头更新后，只传合法已知的地形。
GameFX.setAmbienceEnabled(preferences.ambience);
GameFX.setScene({ terrain: nearestVisibleCell.terrain, active: true });

// 菜单、对白、后台页面等场景停止环境声。
GameFX.setScene({ active: false });

// 与游戏和动画一起暂停、恢复。
GameFX.setPaused(true);
GameFX.setPaused(false);

// 换页、读档、重开或关闭时清理动作、标签和环境声。
GameFX.cancel();
```

原有 `capture`、`plan`、`play`、音效静音与音量 API 保持兼容。`settings()` 新增 `ambienceEnabled`、`scene: { active, profile }`、`ambienceRunning`。环境开关与原音效偏好一起保存；场景是否正在运行只保留在内存，不写入对局存档。

`play()` 开始新动作时仅清理上一动作的声音与画面，保留仍然活跃的环境声。普通 `cancel()` 会同时结束环境声。曾经通过手势成功解锁音频后，暂停时再次调用 `unlock()` 不会丢失恢复权限；浏览器拒绝恢复音频时仍正常完成游戏动作。

## 验证与范围

`node scripts/verify-fx.js` 共 **25 组通过**。前 17 组覆盖单位及技能映射、实际路线、隐藏碰撞、迷雾、实际攻击反击、致死、建筑毁坏、修复量、动画不改状态、暂停恢复、无刷新帧时取消、音频门控与失败恢复；新增 8 组直接检查核心移动自动占领与 FIFO 出库、回合批量产出、隐藏敌方出库、手动部署去重和 600 条事件截断、顶层标签恢复、场景分类、重复更新的节点及缓存边界、空间声像与取消后的断连。

报告为 `reports/fx-tests-v0.9.json`。本轮使用 Node 下确定性的 DOM、RAF 和音频节点模型验证，不进行浏览器操作或人耳听测；因此测试结果不等同于所有设备上的音量、听感或浏览器绘制体验验证。
