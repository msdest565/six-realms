# 六域：动作与声音设计 v0.8

所有效果为本地原创 SVG 和 Web Audio 合成，不依赖音频文件、下载、第三方引擎或网络请求。动作只展示已经成功结算的事务，不更改生命值、移动消耗、伤害、占领或技能规则。

## 信息与节奏

移动仅播放真实终点以前已经走过的路线。撞见隐藏单位时在阻挡格前停止；可见路段被迷雾隔开时分段显示，中间不画穿过隐藏区域的连接线。完全无法看到的 AI 行动不产生视觉或声音。只看到目标命中时只显示命中，不泄露攻击者坐标、型号、弹道来源或隐藏血量。未知的攻击前血量不会换算为伤害数字。

普通移动每格约 135—205 毫秒；射击、命中及合法反击依次播放，单次动作通常小于两秒。快速 AI 使用 36% 时长；系统“减少动态效果”使用 14% 时长并去掉步态及后坐振动，最短阶段 40 毫秒。声音使用独立的静音和音量设置，最大合成输出受主音量和压缩器控制。

空格暂停由 UI 同时暂停游戏调度与 GameFX。动画停留在当前进度，音频上下文暂停；恢复后接着播放。换页、读档或重开对局调用 `cancel()`，立即恢复底层图像并结束动画 Promise，浏览器停止刷新动画帧时也不会阻塞读档。

浏览器音频必须通过人类点击或键盘手势调用 `unlock()` 才启动。自动运行的 AI 无权自行创建音频上下文。系统或浏览器拒绝音频启动时游戏仍可正常操作。

## 集成接口

```js
GameFX.unlock(); // 在人类 pointerdown / keydown 的处理器中调用
const before = GameFX.capture(state, command, viewerId);
const result = Game.execute(state, command);
if (!result.ok) return;
render(); // 展示最终状态；UI 保持 busy，避免第二条指令或下一次 AI 行动
await GameFX.play({
  before, after: state, command, viewerId,
  board: document.getElementById('board'), xy,
  fast: fastAI,
  spriteScale: .46,
  unitOffset: { x: -23, y: -29 }
});
// 解除 busy 后显示已结算的剧情或进入下一条指令。
```

`capture()` 返回执行前可见实体；隐藏路线和实体仅存在于模块内部的短期 WeakMap，不进入存档或公开效果计划。`plan()` 可单独生成可见动作序列供回归测试。地图原图像应分别包裹 `data-unit-sprite="实例ID"` 和 `data-building-sprite="实例ID"`；可附 `data-sprite-offset="x,y"`、`data-sprite-scale="比例"`。动画中仅隐藏对应图像并叠加原单位或建筑的执行前画面，完成、取消或异常后恢复原透明度。

设置接口为 `setEnabled(bool)`、`setSoundEnabled(bool)`、`setVolume(0..1)`、`setPaused(bool)`、`settings()`。动画及声音偏好单独存储为 `six-realms-fx-v0.8`，不修改任何对局存档。

## 验证范围

运行 `node scripts/verify-fx.js`，验证全部单位与技能的效果映射、真实绕行及隐藏碰撞、迷雾路段裁剪、实际攻击和反击伤害、致死与建筑毁坏、实际修复量、动画不改规则状态、暂停和恢复、无刷新帧时取消、缺少地图节点、切换播放清理、音频手势门控及拒绝恢复处理。测试使用确定性的 DOM / RAF 驱动，不把这种测试等同于浏览器绘制或人耳听测；浏览器视觉集成检查见本次交付的验收记录。
